# Maximal Game Try

## Definition

A **Maximal Game Try (MGT)** is a game-invitation method used **after the opponents interfere** following a major-suit raise.

Instead of using a natural trial suit, opener makes a **cue bid of the opponents' suit** to invite game.

The convention preserves game-try sequences that would otherwise be lost because the opponents have occupied bidding space.

The basic message is:

> **"I have extra values and would have made a game try if the opponents had not interfered."**

---

# Purpose

The convention allows the partnership to

- retain game-invitation capability,
- distinguish between competitive and invitational auctions,
- avoid ambiguity,
- reach sound games,
- stop safely in partscore,
- use available bidding space efficiently.

Without Maximal Game Try, many normal game-try bids become unavailable.

---

# Why Is It Needed?

Consider the uncontested auction

```
South      North

1♠
2♠
3♣
```

The bid of 3♣ could be

- Help Suit Game Try
- Long Suit Game Try
- Short Suit Game Try

depending upon partnership agreement.

Now suppose West interferes.

```
South      West      North

1♠         Pass      2♠
3♣
?
```

If opener now bids

```
3♦
```

is it

- natural?
- competitive?
- game try?

The meaning becomes unclear.

Maximal Game Try solves this problem.

---

# Basic Principle

After the opponents compete,

the **cue bid of their suit** becomes the game try.

Example

```
South      West      North      East

1♠         Pass      2♠         3♣
4♣
```

The

```
4♣
```

bid is **not** natural.

It simply says

> "Partner, I have extra values. Please evaluate for game."

---

# Origin of the Name

The word **Maximal** refers to the fact that the partnership uses the **maximum available bidding space** below game for an invitation.

The opponents have already consumed bidding room.

Rather than inventing new meanings for the remaining natural bids,

the cue bid becomes the artificial invitation.

---

# Objectives

Maximal Game Try aims to

- preserve invitational bidding,
- separate competitive bids from game tries,
- improve partnership judgment,
- avoid misunderstandings,
- reach good games,
- avoid poor games.

---

# When Is Maximal Game Try Used?

The convention applies only after

1. A major-suit fit has been established.
2. The opponents interfere below game.
3. Game remains uncertain.

# Advantages

Maximal Game Try

- Preserves game invitations after interference.
- Eliminates ambiguity.
- Works with all game-try philosophies.
- Simple to remember.
- Widely played by tournament partnerships.
- Fits naturally into competitive bidding.

---

# Disadvantages

The method also has limitations.

- Requires explicit partnership agreement.
- Uses the cue bid artificially.
- Gives opponents some information.
- Applies only in competitive auctions.

Despite these limitations,

it is one of the most widely adopted competitive bidding treatments in modern bridge.

---

# Relationship to Other Game Tries

Maximal Game Try is unique because it does **not** replace

- Help Suit Game Try,
- Long Suit Game Try,
- Short Suit Game Try.

Instead, it **preserves the ability to invite game when interference makes those methods impractical**.

It therefore complements rather than competes with the other game-try methods.

---

The Maximal Game Try operates on a simple principle:

> **When the opponents consume bidding space, the cue bid of their suit becomes the game invitation.**

Instead of using a natural trial suit, opener bids the opponents' suit artificially.

Responder then decides whether to bid game.

# Advanced Philosophy

Maximal Game Try is based upon one simple idea:

> **Competition should not prevent accurate game bidding.**

Without interference, partnerships can use

- Help Suit Game Tries,
- Long Suit Game Tries,
- Short Suit Game Tries,

to investigate game.

When opponents interfere, those natural bids may disappear.

Rather than abandoning game investigation,

the partnership transfers the invitation to the **cue bid of the opponents' suit**.

# Summary

The **Maximal Game Try** is an elegant competitive bidding treatment that
allows a partnership to preserve game invitations after the opponents have
interfered.

Instead of using a natural trial suit, opener cue bids the opponents' suit
to say:

> **"I have extra values. Please evaluate your hand for game."**

Responder considers

- trump quality,
- controls,
- distribution,
- offensive potential,
- overall playing strength,

rather than evaluating a specific side suit.

The convention removes ambiguity between competitive raises and genuine game
invitations, making it one of the standard tools of modern tournament bridge.

---

# Key Points

- Maximal Game Try is used **only after the opponents interfere** following a major-suit raise.
- The **cue bid of the opponents' suit** becomes an artificial game invitation.
- The cue bid does **not** show control, length, or a stopper.
- The convention distinguishes competitive raises from invitational sequences.
- Responder evaluates overall offensive strength rather than a specific suit.
- Trump quality, controls, distribution, and Losing Trick Count are key evaluation factors.
- Maximal Game Try complements rather than replaces Help Suit, Long Suit, and Short Suit Game Tries.
- It is widely played in SAYC, 2/1, Acol, Precision, Polish Club, and other natural systems.
- Clear partnership agreements regarding continuations and interference are essential.

# Implementation Notes

## Recommended Partnership Agreement

For most modern natural partnerships (SAYC, 2/1, Acol, and Polish Club), the following treatment is recommended:

- A cue bid of the opponents' suit immediately after a simple major-suit raise and competitive interference is **Maximal Game Try**.
- A direct return to the agreed major is **competitive only**, showing no game interest.
- Jumping directly to game shows a hand that accepts the risk without needing partner's evaluation.
- All natural Help Suit, Long Suit, or Short Suit Game Tries are **replaced** by Maximal Game Try whenever the cue bid is available.

This agreement is the one most commonly found in modern tournament bridge literature and provides the clearest distinction between competitive and invitational auctions.

# Final Takeaway

Maximal Game Try is not a separate hand-evaluation method like Help Suit, Long Suit, or Short Suit Game Tries. Instead, it is a **competitive framework** that preserves the ability to make a game invitation after the opponents have taken away the normal bidding space.

For modern tournament partnerships, it is considered an essential component of competitive major-suit bidding.
