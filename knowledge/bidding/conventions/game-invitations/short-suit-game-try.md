# Short Suit Game Try (SSGT)

## Definition

A **Short Suit Game Try (SSGT)** is a natural **game-invitation method** used after a major-suit fit has been established. Opener bids a **short suit** (typically a singleton or void) to show distributional strength and invite responder to bid game if responder's hand fits well with that shortness.

Unlike the Help Suit Game Try, which asks partner for help in a weak suit, or the Long Suit Game Try, which shows a potential source of tricks, the Short Suit Game Try says:

> **"My shortness will create extra tricks if your hand fits it."**

The convention is based on the principle that **shortness opposite partner's strength is extremely valuable**, while shortness opposite partner's weakness contributes little.

---

# Purpose

The Short Suit Game Try helps determine whether:

- Distribution compensates for limited high-card strength.
- Shortness will generate ruffing tricks.
- Partner's values fit opener's hand.
- Game has sufficient trick-taking potential.

The convention allows the partnership to evaluate **playing strength** rather than simply counting high-card points.

---

# Philosophy

The fundamental idea behind the Short Suit Game Try is:

> **Shortness creates tricks.**

Once a trump fit has been established, declarer can often:

- Ruff losers.
- Establish side suits.
- Eliminate losers.
- Gain extra entries.
- Improve timing.

A singleton or void frequently produces one or more additional tricks.

---

# Historical Background

As bridge bidding evolved, experts realized that:

- High-card points alone were insufficient.
- Distribution frequently outweighed point count.
- Singleton and void holdings dramatically increased trick-taking potential.

Several methods were developed to describe distributional hands.

These included:

- Splinter Bids
- Short Suit Game Tries
- Two-Way Game Tries
- Various artificial game-try methods

Today, the Short Suit Game Try remains a popular expert treatment, particularly among partnerships emphasizing distributional evaluation.

# Advanced Philosophy

The Short Suit Game Try is based upon one of the most important concepts in
modern bridge:

> **Distribution creates tricks.**

Unlike High Card Point (HCP) evaluation, distribution measures how efficiently
the partnership's cards work together.

A singleton or void frequently creates

- ruffing opportunities,
- transportation,
- elimination plays,
- squeeze opportunities,
- loser reduction.

Expert partnerships therefore value **shape** almost as highly as strength.

Hand A is frequently superior after a major fit because

- the singleton creates ruffs,
- club length develops winners,
- honors are concentrated.

The point count alone fails to reveal this difference.

- transportation.

The objective is

> **How many tricks can this partnership actually take?**

---

# Ruffing Values

The principal source of strength is

**ruffing losers in the short hand.**

Example

```
♠ AKQ84
♥ AQ4
♦ 5
♣ AJ97
```

If diamonds are led repeatedly,

opener may ruff one or two rounds,

creating additional tricks unavailable in a balanced hand.

---

# Wasted Values

Experts constantly ask

> "Where are partner's honors?"

Example

Opener

```
♦ 5
```

Responder

```
♦ AQJ
```

The Ace remains useful,

but

- Queen,
- Jack,

often become wasted.

Those honors contribute much less than their HCP suggest.

---

# Working Values

Now compare

Responder

```
♣ AQJ
```

These honors support opener's long club suit.

Their trick-taking value is dramatically higher.

---

# Double Fits

One of the strongest reasons for accepting a Short Suit Game Try is a
**double fit**.

Example

Opener

```
♠ AQJ84
♣ AQ984
♦ 6
```

Responder

```
♠ K95
♣ K74
```

The partnership has

- trump fit,
- side-suit fit,
- singleton,
- excellent offensive potential.

---

# Loser Count

Many expert players evaluate

- losers,
- ruffing potential,
- side-suit winners,

rather than HCP.

Singletons often reduce the expected loser count by one.

---

# Choosing the Short Suit

The short suit should

- genuinely create ruffing opportunities,
- contribute offensive value,
- not merely describe shape.

Example

```
5-4-3-1
```

```

```

Advantages

---

### Void

Advantages

- excellent slam prospects.

Disadvantages

- occasionally difficult to describe naturally.

Such hands generally choose another game-try method.

# Expert Recommendations

Expert partnerships do not accept or reject a Short Suit Game Try by counting
high-card points alone.

Instead, responder evaluates

- location of honors,
- wasted values,
- offensive potential,
- trump quality,
- controls,
- distribution,
- expected trick production.

The guiding question is

> **"Do my cards work well with opener's shortness?"**

---

# Offensive Thinking

The convention rewards partnerships that think in terms of

- tricks,
- ruffs,
- transportation,
- entries,
- suit establishment,

rather than simply HCP.

Many successful games depend upon one additional ruff created by opener's
singleton or void.

---

# Evaluating Honors

Not all honors are equal.

Example

Excellent

```
♣ AQJ
```

when opener has long clubs.

Poor

```
♦ AQJ
```

when opener has a singleton diamond.

Experts constantly ask

> **"Are my honors working?"**

---

# Evaluating Trump Support

Trump quality remains essential.

Excellent

```
K1095
```

Very Good

```
QJ94
```

Adequate

```
Q873
```

Weak

```
7432
```

Even excellent distribution cannot fully compensate for poor trump support.

---

# Losing Trick Count

Short Suit Game Tries work particularly well with

**Losing Trick Count (LTC).**

Shortness often removes one expected loser,

making game significantly more attractive.

Many expert partnerships combine

- distribution,
- LTC,
- working values

when evaluating invitations.

---

# Matchpoints versus IMPs

## Matchpoints

Partnerships tend to be conservative.

A poor game loses many matchpoints.

Overtricks are valuable.

---

## IMPs

Making game is rewarded heavily.

Experts often accept close invitations with

- excellent fit,
- good distribution,
- strong offensive potential.

### Favorable Vulnerability

Slightly aggressive bidding is reasonable.

---

### Unfavorable Vulnerability

Marginal games deserve greater caution.

Third-seat openings are often lighter.

A borderline Short Suit Game Try after a light opening deserves careful evaluation.

# Comparison with Splinter Bids

Although both describe shortness,

# Summary

The **Short Suit Game Try** is an invitational bidding method that uses
**distributional strength** rather than raw high-card strength to evaluate
whether a partnership should bid game.

By showing a singleton or void, opener communicates that

- ruffing opportunities exist,
- offensive potential is increased,
- honors opposite the short suit may be wasted,
- honors elsewhere become especially valuable.

Responder then evaluates

- wasted honors,
- fitting values,
- trump support,
- controls,
- distribution,
- overall trick-taking potential.

The method provides a sophisticated way to distinguish between hands with
identical HCP but dramatically different offensive capabilities.

---

# Key Points

- A Short Suit Game Try shows a singleton or void after a major-suit fit has been established.
- It is an **invitational** method, not a game force.
- The convention emphasizes **distribution and ruffing value**.
- Honors opposite opener's short suit are often wasted.
- Honors supporting opener's long suits become more valuable.
- Trump quality, controls, and Losing Trick Count remain important evaluation tools.
- Partnership agreements should define what constitutes shortness and how the method operates after interference.
- Short Suit Game Tries integrate naturally with Two-Way Game Try structures and complement Splinter Bids.
- Successful use depends on evaluating **playing strength and fit**, not simply counting HCP.
