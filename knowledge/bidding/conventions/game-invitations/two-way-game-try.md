# Two-Way Game Try (TWGT)

## Definition

A **Two-Way Game Try (TWGT)** is an advanced game-invitation structure that allows opener to distinguish between **Long Suit Game Tries** and **Short Suit Game Tries** after a major-suit fit has been established.

Instead of using every new suit bid with the same meaning, the partnership assigns **different meanings to different bids**, enabling opener to describe the hand much more accurately.

The convention combines the strengths of multiple game-try methods into a single integrated system.

---

# Basic Philosophy

Traditional game-try methods ask opener to choose **one** approach:

- Help Suit Game Try
- Long Suit Game Try
- Short Suit Game Try

Two-Way Game Try removes this restriction.

Instead, opener can communicate

- "I have a strong long suit."

or

- "I have useful shortness."

The partnership therefore receives far more information before deciding whether to bid game.

---

# Fundamental Principle

The convention is based upon one important idea:

> **Different hands require different game tries.**

Consider two hands.

Hand A

```
♠ AKQ85
♥ A4
♦ AQJ87
♣ 75
```

The extra tricks will come from

- establishing diamonds.

A Long Suit Game Try is ideal.

---

Hand B

```
♠ AKQ85
♥ A4
♦ 5
♣ AQJ87
```

The extra tricks will come from

- diamond shortness,
- club strength,
- ruffing losers.

A Short Suit Game Try is ideal.

Although the auctions begin identically,

the correct invitation should be different.

---

# Purpose

Two-Way Game Try allows the partnership to

- describe the hand more precisely,
- improve responder's evaluation,
- identify the source of extra tricks,
- distinguish long suits from short suits,
- improve game decisions,
- reduce guesswork.

---

# Why Was It Developed?

Bridge experts recognized that

one natural game-try method could not describe every hand effectively.

Example

```
1♠
2♠
3♦
```

Depending upon partnership agreement,

this auction might mean

- Help Suit Game Try,
- Long Suit Game Try,
- Short Suit Game Try.

Only one interpretation can be correct.

Two-Way Game Try eliminates this ambiguity.

---

# Basic Structure

A partnership assigns

one group of bids to

**Long Suit Game Tries**

and

another group to

**Short Suit Game Tries**.

Exactly which bids belong to each category depends upon partnership agreement.

---

↓

---

↓

---

There is **no universal standard**.

# Objectives

The convention seeks to

- maximize descriptive bidding,
- improve partnership judgment,
- identify offensive strength,
- identify distribution,
- distinguish different hand types,
- improve bidding accuracy.

- partnership has agreed a trump fit.

# Advantages

Two-Way Game Try

- Describes hands accurately.
- Combines multiple game-try methods.
- Improves responder's evaluation.
- Rewards partnership agreements.
- Reduces guesswork.
- Improves competitive results.

---

# Disadvantages

The convention also has limitations.

- Requires extensive partnership discussion.
- More memory than simple game tries.
- Different expert partnerships use different structures.
- Unsuitable for inexperienced players.

---

# Relationship to Other Game Tries

Two-Way Game Try does **not** replace

- Long Suit Game Try,
- Short Suit Game Try.

Instead,

it provides a structure for using **both methods simultaneously**.

It therefore represents a natural evolution of modern game-try bidding.

---

# Key Concepts Introduced

Two-Way Game Try is built upon

- Long Suit Game Try
- Short Suit Game Try
- Offensive hand evaluation
- Distribution
- Working values
- Partnership agreements
- Major-suit game invitations

These concepts form the basis for the detailed bidding structure, responder evaluation, continuations, and expert treatments discussed in the following sections.

# Summary

The mechanics of the Two-Way Game Try revolve around one principle:

> **Different hand types deserve different invitations.**

Responder evaluates differently depending upon whether opener shows

- a long suit,
- shortness,
- or another agreed structure.

This flexibility allows advanced partnerships to make significantly more accurate game decisions than any single game-try method alone.

# Introduction

Unlike Help Suit, Long Suit, or Short Suit Game Tries, there is **no single
standard auction** for Two-Way Game Try.

The examples in this chapter assume the following partnership agreement:

- **Cheapest available new suit = Long Suit Game Try**
- **Next available suit = Short Suit Game Try**

This is one of the most common natural approaches.

If your partnership uses another structure, the evaluation principles remain
the same even though the bids themselves may differ.

# Common Evaluation Errors

Responder often

- evaluates the wrong suit,
- ignores partnership agreement,
- forgets whether the bid shows longness or shortness,
- counts only HCP.

# Lessons from the Examples

The examples demonstrate several important principles:

- The same responder hand may accept one type of game try and reject another.
- Correct hand evaluation depends entirely on understanding **what opener is trying to communicate**.
- Two-Way Game Try provides more accurate information than any single natural game-try method.
- The convention rewards partnerships that evaluate **fit, distribution, and offensive potential** rather than simply counting high-card points.
- Partnership agreement is more important than the specific structure chosen.

# Advanced Philosophy

The Two-Way Game Try represents the evolution of natural game-invitation methods.

Instead of asking

> **"Which single game try should we play?"**

expert partnerships ask

> **"Why limit ourselves to only one?"**

The convention recognizes that different hands create extra tricks in different
ways.

Some hands rely upon

- establishing long suits.

Others rely upon

- shortness,
- ruffing,
- distribution.

The bidding method should reflect that difference.

---

# Evolution of Game Tries

The development of game-try methods roughly followed this progression

```
Simple Invitation

↓

Help Suit Game Try

↓

Long Suit Game Try

↓

Short Suit Game Try

↓

Two-Way Game Try

↓

Artificial Game Tries
```

Each stage provides

- greater description,
- improved hand evaluation,
- better partnership decisions.

---

# Why Two-Way Works

Traditional methods force opener to describe every hand using

only one philosophy.

Two-Way Game Try allows opener to choose the description that best matches the hand.

Example

Extra tricks from

```
AQJ1097
```

↓

Long Suit

---

Extra tricks from

```
singleton
```

↓

Short Suit

Responder immediately knows

where the offensive potential comes from.

---

# Different Sources of Tricks

Long Suit hands produce

- established winners,
- discards,
- transportation,
- squeeze potential.

---

Short Suit hands produce

- ruffs,
- loser reduction,
- crossruff possibilities,
- elimination plays.

Because these are fundamentally different,

experts prefer different game tries.

---

# Modern Partnership Philosophy

World-class partnerships rarely believe

one game-try method fits every auction.

Instead they combine

- Long Suit
- Short Suit
- Help Suit
- Maximal
- Artificial methods

according to the auction.

Two-Way Game Try is therefore a **framework**, not a rigid convention.

# Expert Recommendations

The Two-Way Game Try is one of the most sophisticated natural game-invitation
methods because it recognizes that **different hands create extra tricks in
different ways**.

Expert partnerships do not evaluate every invitation identically.

Instead they first determine

- **what type of game try opener has made**, and then
- **whether responder's hand fits that specific type**.

This produces more accurate game decisions than any single-method approach.

---

# General Evaluation

Responder should follow two steps.

## Step 1

Identify the agreed game-try type.

Is opener showing

- Long Suit?
- Short Suit?
- Artificial relay?
- Another agreed structure?

Without this information,

correct evaluation is impossible.

---

## Step 2

Evaluate the hand appropriately.

### Long Suit

Upgrade

- honors in opener's suit,
- entries,
- intermediates,
- controls.

---

### Short Suit

Upgrade

- honors outside the short suit,
- trump support,
- controls,
- distribution.

Downgrade

- honors opposite opener's shortness.

# Summary

The **Two-Way Game Try** is an advanced partnership treatment that combines
Long Suit and Short Suit Game Tries into a unified bidding structure.

Instead of forcing every invitational hand into a single method, opener
describes **how the extra tricks are expected to be generated**.

Responder then evaluates the hand using criteria appropriate to that type of
game try.

The result is more accurate hand evaluation, better game decisions, and a
partnership style that reflects modern offensive bridge.

Because no universal structure exists, **clear partnership agreement is more
important than the specific method chosen**.

---

# Key Points

- Two-Way Game Try is a **partnership treatment**, not a universally standardized convention.
- It combines Long Suit and Short Suit Game Tries into one structure.
- Different partnerships use different bidding schemes.
- Long Suit Game Tries focus on establishing winners.
- Short Suit Game Tries focus on ruffing values and distribution.
- Responder must know which type of game try has been made before evaluating the hand.
- Most partnerships suspend Two-Way Game Tries after interference and use Maximal Game Try instead.
- The method integrates naturally with modern hand evaluation techniques such as Working Values and Losing Trick Count.
- Explicit partnership agreements are essential for successful use.
