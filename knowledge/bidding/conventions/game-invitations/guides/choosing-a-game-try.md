# Choosing a Game Try

## Purpose

Knowing **which** Game Try to use is often more important than mastering every
available convention.

Different auctions require different tools.

This guide provides a practical framework for selecting the most appropriate
Game Try.

Unlike the individual convention articles, this document focuses on **decision
making** rather than explaining each convention.

# Which Method Best Fits Your Hand?

| Hand Type | Best Choice |
|-----------|-------------|
| Weak side suit | Help Suit |
| Long side suit | Long Suit |
| Singleton or void | Short Suit |
| Long suit or shortness | Two-Way |
| Competitive auction | Maximal |
| Artificial partnership | Artificial |
| Relay partnership | Artificial 2NT |

---

# Which Method Fits Your Partnership?

| Partnership Style | Recommended |
|-------------------|-------------|
| Casual | Help Suit |
| Club | Help Suit + Maximal |
| Tournament | Long + Short + Maximal |
| Expert | Artificial + 2NT |

---

# Advantages of Simplicity

Many partnerships achieve better results using

- Help Suit
- Long Suit
- Maximal

than attempting sophisticated artificial methods without complete agreements.

Always choose the most advanced method that **both partners can remember
accurately**.

---

# Recommended Learning Order

1. Help Suit Game Try
2. Long Suit Game Try
3. Short Suit Game Try
4. Maximal Game Try
5. Two-Way Game Try
6. Artificial Game Try
7. Artificial 2NT Game Try

Each convention builds naturally on the concepts introduced by the previous
ones.

---

# Common Mistakes

- Using Maximal without interference.
- Showing shortness with Long Suit methods.
- Forgetting partnership agreements.
- Playing Artificial methods without documented continuations.
- Selecting complexity instead of consistency.

---

# Expert Advice

There is **no universally best Game Try**.

The best choice depends on

- the auction,
- the partnership,
- the bidding system,
- the level of competition,
- and the hand itself.

The strongest partnerships are not those with the most conventions, but those
that consistently choose the right convention for the situation.
