# Mixed Raise

## Overview

The **Mixed Raise** is a conventional response used in **competitive auctions**
to distinguish a hand that is **too strong for a purely preemptive raise but too
weak for a limit raise**.

It combines constructive and obstructive values by showing

- at least four-card trump support,
- approximately **7–10 support points**,
- offensive distribution,
- interest in competing to the three level,
- but **insufficient strength for an invitational raise**.

Without the Mixed Raise, these hands are difficult to describe accurately,
forcing responder either to underbid with a preemptive raise or overbid with a
limit raise.

---

# Objectives

The Mixed Raise allows the partnership to

- distinguish constructive raises from purely preemptive raises,
- compete accurately,
- make life difficult for the opponents,
- avoid missing games,
- improve competitive judgment.

# Typical Auction

```
West      North      East      South
           1♥         2♣
3♣*
```

or

```
West      North      East      South
           1♠         2♦
3♦*
```

The cue bid of the opponent's suit shows a **Mixed Raise**.

Some partnerships instead use

```
3♥
```

or

```
3♠
```

depending on their agreements.

---

# Requirements

Typical requirements are

- four-card or longer trump support,
- approximately **7–10 support points**,
- offensive shape,
- shortage or distribution preferred,
- no game-forcing values.

Support points include

- High Card Points,
- distribution,
- shortness.

---

# Support Point Evaluation

Mixed Raises are evaluated using **support points**, not raw HCP.

Upgrade for

- singleton,
- void,
- fifth trump,
- excellent trump quality.

Downgrade for

- flat shape,
- scattered honors,
- poor trump support.

---

# Partnership Agreements

Partnerships should define

- minimum support,
- point range,
- whether cue bids or jump raises are used,
- vulnerability adjustments,
- continuation methods.

---

# Common Treatments

## Cue Bid Method

Most expert partnerships use

```
1♥ — (2♣)
3♣*
```

Opponent's suit = Mixed Raise.

Advantages

- leaves jump raises available,
- clearly distinguishes hand types,
- conserves bidding space.

---

## Jump Raise Method

Some partnerships use

```
1♠ — (2♦)
3♠
```

as Mixed Raise,

while using another treatment for purely preemptive raises.

Less common among experts.

# Continuations

After a Mixed Raise,

opener evaluates

- hand strength,
- offensive controls,
- trump quality,
- distribution,
- vulnerability.

Possible continuations include

- Pass
- Compete further
- Invite game
- Bid game

---

# Vulnerability

Vulnerability significantly influences Mixed Raise style.

**Favorable Vulnerability**

- More aggressive
- Lighter values
- Greater emphasis on obstruction

**Unfavorable Vulnerability**

- Better trump quality
- Better playing strength
- More disciplined style

---

# Expert Style

Modern expert partnerships prefer the Mixed Raise because it

- describes intermediate strength accurately,
- interferes with the opponents,
- preserves room for stronger raises,
- improves competitive judgment.

It has become standard in serious tournament partnerships.

---

# Advantages

- Better hand classification
- Improved competitive accuracy
- Greater preemptive pressure
- More descriptive bidding
- Easier game decisions

---

# Disadvantages

- Requires partnership agreement
- Several possible treatments exist
- May consume cue bids needed for other purposes

---

# Common Mistakes

## Treating It as a Limit Raise

Mixed Raises are weaker than limit raises.

---

## Ignoring Distribution

Support points are more important than HCP.

---

## Using Only Three Trumps

Expert methods normally require at least four-card support.

---

## Forgetting Vulnerability

Aggressiveness should depend on vulnerability.

---

## Confusing Partnership Agreements

Always define

- cue bid meaning,
- jump raise meaning,
- continuation structure.

# Summary

The **Mixed Raise** is an expert competitive convention that fills the gap
between a **preemptive raise** and a **limit raise**. By showing **approximately
7–10 support points**, at least **four-card trump support**, and offensive
distribution, it allows responder to compete aggressively while accurately
describing hand strength.

Widely used in modern tournament bridge, the Mixed Raise improves competitive
judgment, increases preemptive pressure on the opponents, and enables opener to
make more informed decisions about competing, inviting game, or bidding game.
