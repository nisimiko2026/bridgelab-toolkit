# Passed Hand Splinter

## Overview

A **Passed Hand Splinter** is an artificial jump response by a responder who has
previously passed. It shows

- excellent trump support,
- singleton or void in the bid suit,
- constructive values,
- game interest,
- but **not enough strength for an opening bid**.

Unlike a standard splinter, a Passed Hand Splinter **is not game forcing**.
Instead, it invites opener to evaluate the hand based on fit and wasted values.

Modern expert partnerships use Passed Hand Splinters to maximize descriptive
bidding while avoiding unnecessary game commitments.

---

# Objectives

The convention enables responder to

- show immediate trump support,
- identify shortness,
- distinguish constructive passed-hand raises,
- help opener evaluate wasted honors,
- investigate game efficiently,
- obstruct the opponents.

---

# Why a Separate Convention?

After responder has passed initially,

```
Pass
Pass
1♠
?
```

the partnership knows responder lacks opening strength.

A normal splinter would overstate the hand.

The Passed Hand Splinter fills the gap between

- mixed raises,
- limit raises,
- standard splinters.

---

# Basic Principle

Typical auction

```
Pass
Pass
1♠
4♣*
```

shows

- four-card or better spade support,
- club singleton or void,
- approximately 9–11 support points,
- constructive game invitation.

The bid is artificial.

---

# Hand Requirements

Typical requirements include

- previously passed hand,
- four-card or longer trump support,
- singleton or void,
- approximately 9–11 support points,
- offensive distribution.

The exact range depends on partnership agreement.

---

# Support Evaluation

Passed Hand Splinters are evaluated using

- support points,
- Losing Trick Count,
- playing strength,
- distribution.

Shortness is a major asset.

---

# Shortness

The jump bid shows shortness in the bid suit.

Example

```
1♥
4♠*
```

shows

- heart support,
- singleton or void spade.

Similarly

```
1♠
4♦*
```

shows

- spade support,
- diamond shortness.

# Opener's Evaluation

Opener should evaluate

- wasted honors,
- controls,
- trump quality,
- offensive strength,
- distribution.

Excellent fitting hands frequently accept the invitation.

# Wasted Values

Example

Responder

```
♠ QJ94
♥ K987
♦ 3
♣ AJ82
```

After

```
Pass
Pass
1♥
4♦*
```

singleton diamond.

If opener holds

```
♦ AKQ
```

those values are partly wasted.

Game becomes less attractive.


Responder

```

♥ K983

♣ AQ1082
```

Game is attractive.

# Continuations

Opener may

- Pass
- Bid game
- Cue bid
- Begin slam investigation

depending on

- controls,
- fit,
- wasted values,
- playing strength.

---

# Slam Interest

Passed Hand Splinters rarely indicate slam interest because responder has
already denied opening values.

However,

exceptional fitting hands may still justify

- cue bidding,
- control bids,
- Roman Key Card Blackwood.

---

# Vulnerability

At favorable vulnerability,

expert partnerships become

- slightly more aggressive,
- willing to stretch support values.

At unfavorable vulnerability,

requirements become more disciplined.

---

# Competition

Many partnerships retain Passed Hand Splinters after light competition.

Example

```

Pass
1♠
(2♦)
4♣*
```

Partnership agreement required.

# Partnership Agreements

Partners should define

- point range,
- support requirements,
- singleton versus void,
- forcing status,

- competitive treatments.

# Expert Style

Modern expert partnerships generally treat Passed Hand Splinters as

- constructive,
- highly descriptive,
- game invitational,
- non-forcing.

They complement

- Drury,
- Reverse Drury,
- Mixed Raise,
- Bergen Raises,
- Passed-Hand Jacoby.

---

# Advantages

- Excellent hand description
- Immediate disclosure of shortness
- Better game decisions
- Accurate fit evaluation
- Efficient use of bidding space

# Disadvantages

- Requires detailed agreements
- Several expert variations exist
- Less common among casual partnerships

# Common Mistakes

## Treating It as a Standard Splinter

Responder has already passed.

The bid is generally invitational rather than game forcing.

---

## Ignoring Wasted Values

Opener should downgrade hands with honors opposite responder's short suit.

---

## Too Few Trumps

Experts normally require at least four-card support.

---

## Flat Distribution

Splinters require genuine shortness.

---

## Overvaluing HCP

Distribution and fit outweigh raw point count.

# Expert Recommendations

Modern tournament partnerships frequently employ the following structure after a
passed hand:

| Bid | Meaning |
|------|---------|
| Single Raise | Constructive |
| Drury | Constructive inquiry |
| Reverse Drury | Strong constructive raise |
| Passed-Hand Jacoby | Invitational raise without shortness |
| Passed Hand Splinter | Invitational raise with shortness |

This structure enables responder to distinguish every important type of
supporting hand while allowing opener to evaluate accurately based on fit,
controls, and wasted values.

---

# Summary

The **Passed Hand Splinter** is an advanced conventional raise used after
responder has previously passed. It combines **strong trump support**,
**singleton or void**, and **constructive invitational values**, allowing
opener to evaluate game prospects using fit rather than high-card points.

Although not as widely played as standard splinters or Drury, it is an elegant
expert treatment that complements modern constructive bidding systems by
accurately describing distributional hands while preserving efficient bidding
space.
