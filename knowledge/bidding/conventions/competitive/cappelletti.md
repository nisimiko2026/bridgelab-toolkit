# Cappelletti Convention

## Overview

The **Cappelletti Convention**, also known in some countries as **Hamilton**, is one of the world's most popular defenses against a **1NT opening**. It uses a series of artificial overcalls to describe one-suited and two-suited hands while making it difficult for the opponents to exchange information.

Compared with standard Landy, Cappelletti identifies a much wider range of distributions and is easy to remember, making it suitable for partnerships ranging from intermediate to expert level.

Although some regions distinguish **Hamilton** and **Cappelletti**, many modern partnerships treat them as essentially the same convention with only minor differences.

---

# Purpose

Cappelletti is designed to:

- Compete effectively over 1NT.
- Show one-suited and two-suited hands.
- Locate major-suit fits.
- Preempt the opponents.
- Improve partscore competition.
- Occasionally reach vulnerable games.

---

# When to Use

The convention applies after:

```
(1NT)
?
```

It may be used against:

- Strong Notrump
- Weak Notrump

Many partnerships adopt different strength requirements depending on the opponents' notrump range.

---

# Standard Cappelletti Structure

The most widely played structure is:

| Bid | Meaning |
|------|---------|
| Double | Strong balanced hand (penalty) |
| 2♣ | One long suit (unknown) |
| 2♦ | Both major suits |
| 2♥ | Hearts and a minor |
| 2♠ | Spades and a minor |
| 2NT | Both minor suits |

This version is considered the modern standard.

---

# Double

```
(1NT)
Double
```

Usually shows:

- 15-18 HCP
- Balanced hand
- Interest in defending

Against a weak notrump many partnerships play a pure penalty double.

---

# 2♣ — One Long Suit

```
(1NT)
2♣*
```

Artificial.

Shows:

- One unspecified six-card (or longer) suit.

Responder bids:

```
2♦
```

unless holding a very strong club fit.

Overcaller then corrects to the actual suit.

---

## Example

```
West   North
1NT    2♣*
Pass   2♦
Pass   2♥
```

Shows:

- Long hearts.

---

# 2♦ — Both Majors

```
(1NT)
2♦*
```

Shows:

- Hearts
- Spades

Normally:

- 5-5
- Sometimes strong 5-4

Advancer chooses the preferred major.

---

# 2♥ — Hearts and a Minor

```
(1NT)
2♥*
```

Shows:

- Hearts
- An unspecified minor

Usually:

- 5-5

---

# 2♠ — Spades and a Minor

```
(1NT)
2♠*
```

Shows:

- Spades
- An unspecified minor

Usually:

- 5-5

---

# 2NT — Both Minors

```
(1NT)
2NT*
```

Shows:

- Clubs
- Diamonds

Usually:

- 5-5 or better

---

# Strength Requirements

Typical style:

Against Strong Notrump:

- 10-15 HCP

Against Weak Notrump:

- 12-16 HCP

Excellent distribution often compensates for fewer high-card points.

---

# Suit Quality

Preferred holdings include:

- Two of the top three honors.
- Three of the top five honors.

Distribution is generally more important than raw HCP.

---

# Responses by Advancer

## After 2♣

Responder bids:

```
2♦
```

as a relay.

Overcaller then bids the actual suit.

Example:

```
1NT
2♣*
Pass
2♦
Pass
2♠
```

Shows long spades.

---

## After 2♦

Advancer chooses:

- 2♥
- 2♠

according to preference.

---

## After 2♥

Advancer may:

- Pass.
- Bid the minor.
- Invite.
- Bid game.

---

## After 2♠

Same principles apply.

---

## After 2NT

Advancer selects:

- Clubs
- Diamonds

or invites game.

# Competitive Auctions

## Overview

After Cappelletti enters the auction, the partnership usually continues naturally, taking advantage of the information already exchanged.

---

## Opponent Doubles

Example

```
1NT
2♦*
(Double)
?
```

Typical agreements:

- Pass = Preference.
- Redouble = Values.
- Natural bids.

---

## Opponent Bids Game

Example

```
1NT
2♦*
3NT
?
```

Evaluate:

- Vulnerability.
- Playing tricks.
- Fit.
- Defensive potential.

Sometimes defending is best.

---

## Competition After Relay

Example

```
1NT
2♣*
Pass
2♦
(Double)
?
```

Overcaller normally continues by showing the long suit.

---

## Balancing Position

Many partnerships use the same structure after:

```
1NT

?
```

This should be agreed in advance.

# Comparison with Landy

| Cappelletti | Landy |
|-------------|-------|
| Describes many hand types | Only both majors |
| One-suited hands included | No one-suited treatment |
| More flexible | Simpler |
| Slightly harder to remember | Very easy |

---

# Comparison with Hamilton

Modern treatments generally regard **Hamilton** as a variation of Cappelletti.

The most common difference is:

| Cappelletti | Hamilton |
|-------------|----------|
| 2♣ = One long suit | 2♣ = Clubs + another suit (in some versions) |
| 2♦ = Both majors | 2♦ = Both majors |

Many books use the two names interchangeably.

---

# Advantages

Cappelletti:

- Covers nearly every offensive hand type.
- Easy to learn.
- Excellent competitive tool.
- Highly disruptive.
- Popular worldwide.

---

# Limitations

The convention:

- Gives information to the opponents.
- Requires relay agreements.
- Several published versions exist.
- Less descriptive than some expert methods.

---

# Variations

Popular versions include:

- Standard Cappelletti
- Hamilton
- Modified Cappelletti
- Reverse Cappelletti
- Transfer Cappelletti

Each partnership should define its exact structure.

Aggressive actions should be adjusted according to vulnerability.

# Tips

- Learn Landy before Cappelletti.
- Memorize the standard response table.
- Practice relay auctions.
- Discuss balancing agreements.
- Let vulnerability influence your style.

# Modern Usage

Cappelletti remains one of the most widely played defenses to a 1NT opening.

It is popular in:

- Standard American
- 2/1 Game Force
- SAYC
- Precision
- Acol
- Club systems

Many partnerships adopt the **Hamilton** name while using essentially the same bidding structure.

---

# Summary

The Cappelletti Convention is one of the most versatile and widely played defenses against a 1NT opening. By combining artificial overcalls that show one-suited and two-suited hands, it enables partnerships to compete aggressively, locate major-suit fits, and disrupt the opponents' auction. Although several variations exist, the standard structure remains easy to learn and highly effective, making Cappelletti a cornerstone of modern competitive bidding.
