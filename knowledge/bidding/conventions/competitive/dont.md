# DONT Convention

## Overview

**DONT** (**Disturb Opponents' No Trump**) is one of the most widely played defenses against an opponent's **1NT opening**. Developed by **Marty Bergen**, it uses a combination of natural and artificial calls to show one-suited and two-suited hands while making it difficult for the opponents to exchange information.

Unlike **Cappelletti**, where the Double is usually penalty-oriented, DONT uses the **Double to show a single long suit**, allowing the remaining bids to describe two-suited hands efficiently.

DONT is especially popular because it is:

- Easy to learn.
- Aggressive.
- Flexible.
- Effective against both weak and strong notrump openings.

---

# Purpose

DONT is designed to:

- Compete over 1NT openings.
- Show one-suited and two-suited hands.
- Find major-suit fits.
- Disrupt Stayman and Transfer sequences.
- Increase preemptive pressure.
- Improve partscore results.

---

# When to Use

DONT applies after:

```
(1NT)
?
```

It may be used against:

- Strong Notrump (15-17, 14-16, etc.)
- Weak Notrump (12-14)

Many partnerships become more aggressive against strong notrump.

---

# Standard DONT Structure

The most common structure is:

| Bid | Meaning |
|------|---------|
| Double | One long suit |
| 2♣ | Clubs + a higher suit |
| 2♦ | Diamonds + a higher suit |
| 2♥ | Hearts + Spades |
| 2♠ | Natural spade suit |
| 2NT | Both minors (optional by partnership agreement) |

Some partnerships use a natural 2NT instead.

---

# Double — One Long Suit

```
(1NT)
Double*
```

Shows:

- One unspecified six-card (or longer) suit.

Advancer normally bids:

```
2♣
```

unless holding a very strong hand.

Overcaller then:

- Passes (clubs)
- Corrects to diamonds
- Corrects to hearts
- Corrects to spades

---

## Example

```
West   North
1NT    Double*
Pass   2♣
Pass   2♥
```

Shows:

- Long hearts.

---

# 2♣ — Clubs Plus Higher Suit

```
(1NT)
2♣*
```

Shows:

- Clubs
- Diamonds, Hearts, or Spades

Normally:

- 5-5 or better.

Advancer usually bids:

```
2♦
```

if no clear preference exists.

Overcaller then clarifies the second suit.

---

## Example

```
1NT
2♣*
Pass
2♦
Pass
2♠
```

Shows:

- Clubs and Spades.

---

- 5-5

# 2♥ — Both Majors

```
(1NT)
2♥*
```

Shows:

- Hearts
- Spades

Usually:

- 5-4
- 5-5
- Better

Advancer chooses the preferred major.

---

# 2♠ — Natural

```
(1NT)
2♠
```

Shows:

- Good six-card (or longer) spade suit.

Generally:

- One-suited hand.
- Preemptive.

Some partnerships instead use:

- Spades and a minor.

Agreement is essential.

---

# 2NT

The meaning of **2NT** varies.

Common agreements include:

### Option 1 (Most Common)

```
2NT
```

Shows:

- Both minors.

### Option 2

Natural invitation.

Every partnership should agree.

---

# Strength Requirements

Typical style:

Against Strong NT:

- 8-14 HCP

Against Weak NT:

- 10-16 HCP

Playing strength is considerably more important than HCP.

---

# Suit Quality

Recommended:

- Six-card suit for Double.
- Good five-card suits for two-suited bids.
- Two of top three honors preferred.

# Comparison with Cappelletti

| DONT | Cappelletti |
|------|-------------|
| Double = One suit | Double = Penalty |
| More relay sequences | Simpler structure |
| Slightly more memory | Easier for casual partnerships |

# Comparison with Landy

| DONT | Landy |
|------|-------|
| Covers nearly every hand type | Shows both majors only |
| Artificial Double | Natural Double |
| More complete | Simpler |

# Advantages

DONT:

- Excellent against strong notrump.
- Covers almost every distribution.
- Good preemptive effect.
- Easy to remember.
- Popular worldwide.

---

# Limitations

The convention:

- Requires partnership agreements.
- Artificial bids reveal distribution.
- Relay auctions require practice.
- Several variations exist.

---

# Variations

Common treatments include:

- Standard DONT
- Modified DONT
- Extended DONT
- DONT with Natural 2NT
- DONT with Spades + Minor

Every partnership should define:

- 2♠
- 2NT
- Relay continuations

# Common Mistakes

## Forgetting the Double Relay

The **2♣ relay** is fundamental.

---

## Forgetting "Higher Suit"

Remember:

- Clubs + higher suit.
- Diamonds + higher suit.

---

## Confusing DONT with Cappelletti

The biggest difference is:

**Double**

- DONT = One long suit.
- Cappelletti = Penalty.

---

## Showing Weak Suits

Distribution is valuable.

Suit quality still matters.

---

## Ignoring Vulnerability

Aggressive actions should reflect vulnerability.

# Tips

- Learn Landy before DONT.

- Discuss every optional treatment.

# Modern Usage

DONT remains one of the world's most popular defenses to a 1NT opening.

It is widely played in:

- Standard American
- 2/1 Game Force
- SAYC
- Precision
- Acol
- Club systems

Many tournament partnerships choose DONT because it balances simplicity with excellent descriptive power.

---

# Summary

The DONT Convention (**Disturb Opponents' No Trump**) is a flexible and effective defense against a 1NT opening. By using an artificial **Double** to show a one-suited hand and a series of artificial overcalls to show two-suited hands, DONT enables partnerships to compete aggressively, locate fits, and disrupt the opponents' notrump auction. Its logical structure and broad coverage of offensive hand types have made it one of the most popular and enduring defenses in modern bridge.
