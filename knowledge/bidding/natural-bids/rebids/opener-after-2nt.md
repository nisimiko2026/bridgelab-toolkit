# Opener After a 2NT Opening

## Overview

After opening **2NT**, opener has already described nearly everything about the
hand:

- strength,
- balanced distribution,
- limited range,
- absence of extreme shape.

Unlike suit openings, there is little additional descriptive bidding required.
Instead, opener's primary role is to

- answer responder's conventional bids,
- complete transfer sequences,
- cooperate in slam investigation,
- remain within the agreed strength range.

Since responder knows both hands' combined assets far better than opener,
**responder normally becomes captain of the auction.**

---

# Objectives

After opening 2NT, opener should

- answer conventions accurately,
- preserve bidding space,
- cooperate in game and slam bidding,
- avoid unnecessary description,
- remain faithful to the partnership system.

---

# General Principles

The 2NT opening already defines

- approximately 20–21 HCP,
- balanced hand,
- no singleton,
- no void.

Therefore,

opener should avoid introducing unnecessary information.

Responder determines

- whether a major fit exists,
- whether notrump is best,
- whether slam should be explored.

---

# Accepting Transfers

Transfers are completed automatically.

Example

```
2NT
3♦
3♥
```

Transfer to hearts.

---

```
2NT
3♥
3♠
```

Transfer to spades.

Completing the transfer keeps the strong hand as declarer.

---

# Super Accepts

Some expert partnerships play

Super Accepts.

Example

```
2NT
3♦
4♥
```

May show

- four-card support,
- maximum values,
- excellent trump quality.

Most partnerships simply complete the transfer.

---

# Responding to Stayman

Traditional Stayman

```
2NT
3♣
```

asks opener to show

- four-card major(s).

Typical replies

```
3♦
```

No four-card major.

---

```
3♥
```

Four hearts.

---

```
3♠
```

Four spades.

---

If opener holds both majors,

most partnerships bid

```
3♥
```

unless Puppet Stayman is used.

---

# Responding to Puppet Stayman

Many expert partnerships use

```
2NT
3♣
```

as **Puppet Stayman**.

The exact responses vary, but opener generally

- shows five-card majors first,
- then four-card majors,
- otherwise denies a major.

Puppet Stayman is especially effective for

- locating 5-3 major fits,
- finding 4-4 fits,
- improving slam auctions.

---

# Texas Transfers

Example

```
2NT
4♦
4♥
```

Transfer to hearts.

Likewise

```
2NT
4♥
4♠
```

Transfer to spades.

Transfer completion is automatic.

---

# Minor-Suit Transfers

Many expert partnerships use

```
4♣
```

or

```
4♦
```

to transfer into a minor suit.

When played,

opener accepts the transfer according to partnership agreement.

---

# Quantitative 4NT

Auction

```
2NT
4NT
```

Responder invites slam.

Opener

- passes with a minimum,
- bids 6NT with a maximum.

This is **not** Blackwood.

---

# Gerber

If Gerber is played,

```
2NT
4♣
```

asks for aces.

Typical replies

| Response | Aces |
|----------|------|
| 4♦ | 0 or 4 |
| 4♥ | 1 |
| 4♠ | 2 |
| 4NT | 3 |

Some partnerships instead use 4♣ as a transfer.

Agreement is essential.

---

# Responding to Smolen

When responder employs Smolen,

opener should

- support responder's longer major,
- cooperate naturally,
- continue slam investigation if appropriate.

---

# Invitational Auctions

Although game is normally certain after a 2NT opening,

Responder may occasionally invite slam.

Example

```
2NT
4NT
```

Opener judges

- minimum,
- maximum,
- honor quality,
- controls.

---

# Sign-Off Auctions

Example

```
2NT
3♦
3♥
Pass
```

Opener simply passes.

Responder remains captain.

---

# Slam Investigation

Strong responder hands often initiate slam exploration.

Opener should accurately show

- controls,
- key cards,
- kings,
- cue bids,
- partnership agreements.

Common methods include

- Cue Bidding
- Roman Key Card Blackwood
- Gerber
- Control Bidding
- Exclusion Blackwood

---

# Competitive Auctions

After interference,

partnership agreements should define

- Lebensohl,
- Rubensohl,
- doubles,
- cue bids,
- transfer methods,
- System On/System Off.

---

# Balanced Philosophy

After opening 2NT,

opener should remember

the hand has already been fully described.

Avoid

- speculative bidding,
- unnecessary natural suit bids,
- over-describing the hand.

---

# Declarer Considerations

Transfers are valuable because

they allow opener,

the stronger hand,

to declare the contract.

This

- protects honors,
- conceals information,
- improves play.

---

# Partnership Agreements

Partners should define

- exact 2NT range,
- Stayman or Puppet Stayman,
- Jacoby Transfers,
- Super Accepts,
- Texas Transfers,
- Minor Transfers,
- Smolen,
- Gerber,
- Quantitative 4NT,
- competitive methods.

---

# Summary

After opening **2NT**, opener's task is no longer to describe the hand but to
**cooperate with responder's plan**. Since the opening bid has already defined
both strength and distribution, responder directs the auction while opener
provides precise answers to conventional inquiries.

Successful 2NT continuations rely on disciplined responses to **Stayman**,
**Puppet Stayman**, **Jacoby Transfers**, **Texas Transfers**, **Gerber**, and
**Quantitative 4NT**, together with consistent partnership agreements. The key
to expert 2NT bidding is accuracy, restraint, and efficient use of bidding
space to reach the optimum game or slam.
