# Sign-Off

## Definition

A **sign-off** is a bid that communicates to partner:

> **"I have described my hand sufficiently. Please pass."**

Its purpose is to place the contract at what the bidder believes is the safest or most profitable level. Unlike an invitational or forcing bid, a sign-off is intended to **end the auction immediately**.

---

# Objectives

A sign-off bid aims to:

- Stop the auction.
- Prevent bidding too high.
- Place the contract in the best denomination.
- Limit partnership risk.
- Indicate no interest in further exploration.

---

# Characteristics

A sign-off bid typically:

- Is **non-forcing**.
- Requests partner to pass.
- Shows no slam interest.
- Shows no game invitation (unless game itself is the sign-off).
- Usually limits the bidder's strength.

---

# Typical Situations

Sign-offs occur after:

- Partner opens.
- Partner rebids.
- A forcing sequence ends.
- A transfer is completed.
- A convention asks for the final contract.

Examples include:

- 1NT – Pass
- 1♥ – 2♥
- 1♠ – 4♠
- 1NT – 2♦ (Transfer) – 2♥ – Pass
- Stayman sequences
- Lebensohl continuations
- Blackwood responses after discovering no slam

---

# Types of Sign-Off

## Partscore Sign-Off

Stopping below game.

Example

```
1♥     Pass
2♥
```

Responder wishes to play 2♥.

---

## Game Sign-Off

Stopping exactly in game.

Example

```
1♠
4♠
```

Responder wants to play game without slam investigation.

---

## Notrump Sign-Off

Examples

```
1NT
Pass
```

or

```
1NT
3NT
```

3NT may be a sign-off if responder has no slam interest.

---

## Minor Suit Sign-Off

Example

```
1♦
2♦
```

or

```
1♣
3♣
```

---

# Sign-Off vs Other Calls

| Type | Partner Must Continue? |
|-------|------------------------|
| Sign-Off | No |
| Invitational | May continue |
| Forcing | Yes |
| Game Forcing | Yes |
| Slam Try | Yes |

---

# When is a Bid a Sign-Off?

A bid is a sign-off when:

- No further description is required.
- Partnership has reached the preferred contract.
- Bid is defined as non-forcing by system agreement.

# Sign-Off After Transfers

A transfer frequently ends with a sign-off.

Example

```
1NT
2♥
2♠
Pass
```

Responder has completed the transfer and wishes to play 2♠.

---

# Sign-Off After Stayman

Example

```
1NT
2♣
2♥
Pass
```

Responder is satisfied with hearts.

---

# Sign-Off After Blackwood

After keycards are known:

```
4NT
5♦
5♥
Pass
```

No slam interest remains.

5♥ is the final contract.

---

# Competitive Auctions

A sign-off may occur after interference.

Example

```
1♥
(2♣)
2♥
Pass
```

Responder competes but does not invite further bidding.

---

# Why Sign Off?

Reasons include:

- Minimum values.
- No slam interest.
- No game interest.
- Distribution already described.
- Maximum safety.
- Partnership fit already located.

---

# Partnership Understanding

Both partners must know whether a bid is:

- Sign-off
- Invitational
- Forcing
- Game forcing

Many partnership misunderstandings arise from confusing these categories.

# Common Mistakes

## Bidding Again After Partner Signs Off

Unless holding an unexpected maximum or the system specifically allows it, partner should pass.

---

## Treating Invitational Bids as Sign-Offs

Example:

```
1NT
2NT
```

In most systems this is **invitational**, not a sign-off.

---

## Forgetting System Agreements

Some bids are sign-offs in one system but forcing in another.

Examples:

- Bergen Raises
- Jacoby 2NT
- Lebensohl
- Puppet Stayman
- Transfers

Always follow partnership agreements.

# Memory Aid

A useful guideline is:

> **A sign-off says: "This is our contract. Please pass."**

---

# Key Points

- A sign-off is intended to end the auction.
- It is normally non-forcing.
- It may occur at partscore, game, or occasionally slam level.
- Sign-offs appear throughout natural and artificial bidding systems.
- Correct recognition of sign-off bids prevents partnership misunderstandings.
- Whether a bid is a sign-off always depends on the partnership's agreed system.
