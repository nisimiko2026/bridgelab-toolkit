# Convention Cards

## Purpose

A **Convention Card** is a structured summary of a partnership's bidding, defensive, and carding agreements.

Its primary objectives are to:

- Communicate partnership methods clearly.
- Ensure both partners have the same understanding.
- Meet tournament disclosure requirements.
- Provide a quick reference before and during play.
- Serve as documentation for developing and improving a partnership.

A convention card is **not** a teaching document. It records **what the partnership plays**, not every detail of how a convention works.

---

# Typical Contents

A complete convention card usually includes the following sections.

## General Information

- Partnership names
- System name
- Date or version
- Event or organization (if applicable)

# Good Convention Card Practices

A good convention card should be:

- Accurate
- Complete
- Consistent
- Easy to read
- Updated whenever agreements change

Avoid undocumented partnership understandings.

# Convention Card vs Convention Notes

## Convention Card

Records:

- What the partnership plays.

Example:

```
1NT Opening

15–17 HCP

5-card majors allowed

Jacoby Transfers

Stayman

Texas Transfers
```

---

## Convention Notes

Explain:

- How each agreement works.
- Responses.
- Continuations.
- Competitive sequences.
- Examples.
- Exceptions.

Example:

```
Lebensohl

Purpose

Used after interference over partner's 1NT opening.

...

Examples

...

Follow-up auctions

...
```

# Convention Cards in Duplicate Bridge

Most duplicate bridge organizations require partnerships to disclose their methods.

Convention cards help:

- Opponents understand your agreements.
- Directors resolve misunderstandings.
- Partnerships avoid memory errors.

The exact format varies by governing organization (such as WBF, ACBL, or EBL), but the underlying purpose is the same: **full and accurate disclosure**.

# BridgeLab Convention Cards

In BridgeLab, each convention card should summarize the partnership's agreements without duplicating the detailed documentation stored elsewhere.

A recommended structure is:

```
Convention Card
│
├── System
├── Openings
```

Each item should reference the corresponding detailed Markdown document in the knowledge base.

# Maintenance

Review and update the convention card whenever:

- A convention is added or removed.
- Opening ranges change.
- Defensive methods change.
- Carding agreements change.
- Partnership style evolves.

Version numbers and update dates help ensure both partners are using the same agreements.

# Summary

A convention card is the official summary of a partnership's agreements. It provides a concise, standardized reference covering bidding, competitive methods, slam conventions, and defensive carding. While detailed convention documents explain **how** agreements work, the convention card records **what** the partnership has agreed to play, making it an essential tool for partnership consistency and tournament disclosure.
