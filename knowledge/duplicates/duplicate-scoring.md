````md id="duplicatescoring01"
# Duplicate Scoring

## Overview

**Duplicate Bridge** is designed so that the outcome depends on **skill rather than the luck of the cards**. Every table plays the **same deals**, allowing each partnership's result to be compared directly with others who held the identical cards.

Instead of simply counting tricks won, duplicate bridge converts results into **scores**, which are then compared using one of two principal scoring methods:

- **Matchpoints (Pairs)**
- **International Match Points (IMPs) (Teams)**

The guiding principle is:

> **Your score is determined by how well you perform compared with others holding the same cards.**

---

# Duplicate vs. Rubber Bridge

| Duplicate Bridge | Rubber Bridge |
|------------------|---------------|
| Same boards played at many tables | One deal played once |
| Skill emphasized | Luck has greater influence |
| Boards move between tables | Cards are reshuffled every deal |
| Scores compared with other pairs or teams | Score depends only on one table |

---

# Contract Scoring

The first step is always to calculate the **raw bridge score**.

The score depends on:

- Contract level
- Trump suit
- Doubled or redoubled
- Number of tricks taken
- Vulnerability
- Bonuses and penalties

Example:

```
4♠ Making
Not Vulnerable

Score = 420
```

This raw score is then converted into Matchpoints or IMPs.

---

# Matchpoint Scoring (Pairs)

## Purpose

Each board is compared with every other pair that played the same board.

Every pair receives:

- 2 Matchpoints for every pair they beat.
- 1 Matchpoint for every pair they tie.
- 0 Matchpoints for every pair that scored better.

---

## Example

Board 7

| Pair | Score |
|------|------:|
| A | 620 |
| B | 620 |
| C | 600 |
| D | 170 |

Results:

- A and B tie for top.
- C beats only D.
- D is bottom.

---

## Strategy

Matchpoints reward:

- Overtricks.
- Thin games.
- Aggressive competitive bidding.
- Accurate defense.

Every trick matters.

---

# IMP Scoring (Teams)

## Purpose

The raw score difference between two tables is converted into **International Match Points (IMPs)**.

Small differences:

Small IMP gain.

Large swings:

Large IMP gain.

---

## Example

Open Room

```
4♠ Making

620
```

Closed Room

```
3♠ Making

170
```

Difference

```
450 points
```

Converted to:

```
10 IMPs
```

using the standard IMP conversion table.

# Vulnerability

Vulnerability affects:

- Game bonuses.
- Slam bonuses.
- Undertrick penalties.
- Doubled penalties.

The four vulnerability conditions are:

| Board | Vulnerability |
|--------|---------------|
| None | Neither side vulnerable |
| NS | North-South vulnerable |
| EW | East-West vulnerable |
| Both | Both sides vulnerable |

---

# Board Rotation

Duplicate bridge uses pre-dealt boards.

After each round:

- Boards move.
- Players move.
- Every partnership eventually plays different opponents while holding the same cards as other pairs.

---

# Scoring Priorities

## Matchpoints

Reward:

- Every overtrick.
- Thin games.
- Active competition.
- Slight percentage gains.

---

## IMPs

Reward:

- Making contracts.
- Avoiding large penalties.
- Sound games and slams.
- Conservative overtrick decisions.

---

# Example – Matchpoints

Contract:

```
3NT
```

Making:

```
+430
```

Another pair:

```
+400
```

Difference:

```
30 points
```

At Matchpoints:

```
May be worth an entire top.
```

---

# Example – IMPs

Same scores:

```
430 vs 400
```

Difference:

```
30 points
```

Conversion:

```
1 IMP
```

The gain is relatively small.

---

# Matchpoints vs. IMPs

| Decision | Matchpoints | IMPs |
|----------|-------------|------|
| Overtricks | Very important | Usually secondary |
| Thin Games | Often bid | More cautious |
| Thin Slams | Rarely worthwhile | Bid only with good odds |
| Safety Plays | Sometimes rejected for overtricks | Usually correct |
| Conservative Play | Less rewarded | Highly rewarded |

---

# Common Mistakes

- Using Matchpoint strategy at IMPs.
- Ignoring vulnerability.
- Sacrificing a making contract for an overtrick at IMPs.
- Playing too conservatively at Matchpoints.
- Forgetting that duplicate compares your result with other tables.

---

# Advantages

Duplicate Bridge:

- Rewards skill.
- Reduces the influence of luck.
- Produces fair comparisons.
- Encourages accurate play.
- Suitable for tournaments at every level.

# Player's Checklist

Before every board, ask:

- Is this Matchpoints or IMPs?
- What is the vulnerability?
- Should I prioritize overtricks or contract safety?
- Is bidding game or slam justified?
- What strategy best fits the scoring method?

---

# Memory Guide

## Five Steps

1. Calculate the raw score.
2. Apply vulnerability.
3. Convert to Matchpoints or IMPs.
4. Compare with other tables.
5. Adjust strategy to the scoring method.

---

# Comparison

| Scoring Method | Main Objective |
|----------------|----------------|
| Matchpoints | Beat as many pairs as possible |
| IMPs | Win by the greatest overall margin while avoiding large losses |
| Rubber Bridge | Accumulate points over a rubber |

```

---

# Memory Aid

**Duplicate Bridge = "Play the Same Cards Better Than Everyone Else."**

Remember:

- **Duplicate bridge compares your result with other players holding the same cards.**
- **Matchpoints reward every extra trick; IMPs reward making the contract and avoiding large swings.**
- **Vulnerability significantly affects bonuses and penalties.**
- **Always adjust your bidding and play to the scoring method.**
- **Success in duplicate bridge comes from making the highest-percentage decision for the form of scoring being used.**

Duplicate Bridge is the world's most popular form of tournament bridge because it rewards skill, judgment, and partnership understanding rather than luck in the deal. Mastering the differences between Matchpoint and IMP scoring is essential for becoming a successful competitive player.
````
