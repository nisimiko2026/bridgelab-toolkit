# Count Signals

## Overview

**Count Signals** are defensive signals that communicate the **number of cards** held in the suit being played. Unlike **Attitude Signals**, which tell partner whether to continue a suit, count signals provide information about suit length and distribution.

Count signals help defenders reconstruct declarer's hand, determine when a suit has been exhausted, and coordinate the defense through accurate counting.

The guiding principle is:

> **Tell partner how many cards you hold in the suit.**

---

# Purpose

Count signals help defenders to:

- Show an even or odd number of cards.
- Determine declarer's distribution.
- Locate missing cards.
- Know when a suit is exhausted.
- Improve defensive planning.
- Coordinate suit continuations and switches.

---

# When to Use

Count signals are most useful:

- When partner needs to know the distribution of a suit.
- After attitude has already been established.
- When declarer is running a long suit.
- When deciding whether partner can safely cash winners.
- In suit-preference situations where count has priority.

Count is generally the second priority after attitude.

---

# Standard Count

The most common agreement is:

```
High-Low = Even Number

Low-High = Odd Number
```

Examples:

Holding:

```
♠ 8 3
```

Play:

```
8 then 3
```

Meaning:

```
Even (2 cards)
```

Holding:

```
♥ 2 7 5
```

Play:

```
2 then 7
```

Meaning:

```
Odd (3 cards)
```

---

# Upside-Down Count (UDCA)

Some partnerships use:

```
Low-High = Even

High-Low = Odd
```

This method is called **Upside-Down Count and Attitude (UDCA)**.

Partnership agreement is essential.

---

# Why Count Matters

Knowing partner's length helps determine:

- Whether declarer still has cards in the suit.
- Whether partner can ruff.
- Whether cashing winners is safe.
- Whether a switch is necessary.

---

# Example 1 – Even Count

Contract:

```
3NT
```

Partner leads:

```
♠K
```

You hold:

```
♠ 9 4
```

You play:

```
9
then
4
```

Meaning:

```
Even number of spades.
```

Partner now knows your exact parity.

---

# Example 2 – Odd Count

Partner leads:

```
♦A
```

You hold:

```
♦ 3 8 6
```

You play:

```
3
then
8
```

Meaning:

```
Odd number of diamonds.
```

---

# Count vs. Attitude

Attitude answers:

> **Should partner continue this suit?**

Count answers:

> **How many cards do I hold?**

The two signals serve different purposes.

---

# Count vs. Suit Preference

Count:

```
Number of cards.
```

Suit Preference:

```
Preferred side suit.
```

Suit preference usually becomes important only after count is no longer needed.

---

# Signal Priority

A common priority is:

1. Attitude
2. Count
3. Suit Preference

The partnership should clearly define its priorities.

---

# Advantages

Count signals help defenders:

- Track distribution accurately.
- Count declarer's hand.
- Plan defensive switches.
- Avoid cashing winners prematurely.
- Coordinate defensive play.

---

# Limitations

Count signals:

- May reveal information to declarer.
- Cannot communicate attitude simultaneously.
- Must always be interpreted together with the auction and visible cards.

---

# Common Mistakes

- Giving count when attitude is required.
- Forgetting the partnership agreement.
- Confusing Standard and UDCA.
- Misreading partner's signal.
- Ignoring the context of the hand.

---

# Partnership Agreements

Partners should agree on:

- Standard or Upside-Down Count.
- Signal priorities.
- Whether count is always given or only when useful.
- Exceptions in special situations.

These agreements should appear on the convention card.

# Player's Checklist

When giving count:

- Determine whether partner needs count.
- Follow the partnership agreement.
- Give the agreed count signal.
- Continue counting the entire hand.
- Do not sacrifice higher-priority signals.

---

# Memory Guide

## Four Steps

1. Decide whether count is needed.
2. Determine whether your holding is even or odd.
3. Follow the partnership agreement.
4. Continue reconstructing the unseen hands.

# Memory Aid

**Count Signals = "How Many Cards Do I Have?"**

Remember:

- **Count signals communicate the parity of your holding, not your strength.**
- **The most common agreement is High-Low = Even and Low-High = Odd, although some partnerships play UDCA.**
- **Count usually becomes important after attitude has already been established.**
- **Always interpret count together with the auction, dummy, declarer's play, and previous signals.**
- **Accurate count signals enable defenders to reconstruct the unseen hands and coordinate their defense effectively.**

Count Signals are one of the essential tools of expert defense. By accurately communicating suit length, defenders can count declarer's distribution, time their winners correctly, and cooperate more effectively throughout the play of the hand.
