# Bridge Terminology

## Overview

**Bridge Terminology** is a reference guide to the language used by bridge players, teachers, authors, commentators, and tournament directors. While the **Bridge Glossary** defines individual terms alphabetically, this document groups terminology by topic, making it easier to understand concepts within their proper context.

Learning the correct terminology improves:

- Bidding discussions
- Partnership communication
- Reading bridge books
- Understanding bridge software
- Following expert commentary
- Tournament play

The guiding principle is:

> **Bridge is a language. Mastering its terminology makes every aspect of the game easier to understand.**

---

# Card Terminology

| Term | Meaning |
|------|---------|
| Ace | Highest-ranking card |
| King | Second-highest honor |
| Queen | Third-highest honor |
| Jack | Fourth-highest honor |
| Ten | Fifth-highest honor |
| Spot Card | Any card below the Ten |
| Honor | Ace, King, Queen, Jack, or Ten |
| Intermediate Card | Typically the 10, 9, or 8 |
| Small Card | A low spot card |

---

# Suit Terminology

| Term | Meaning |
|------|---------|
| Major Suit | Hearts or Spades |
| Minor Suit | Clubs or Diamonds |
| Trump Suit | The designated trump suit |
| Side Suit | Any non-trump suit |
| Long Suit | Usually five or more cards |
| Short Suit | Singleton or void |
| Doubleton | Two-card suit |
| Singleton | One-card suit |
| Void | No cards in a suit |
| Fit | Eight or more combined cards in one suit |
| Misfit | No eight-card fit between partners |

# Hand Types

| Term | Meaning |
|------|---------|
| Balanced Hand | No voids, no singletons, at most one doubleton |
| Semi-Balanced | Slightly unbalanced but suitable for Notrump in many cases |
| Unbalanced Hand | Contains a singleton, void, or multiple doubletons |
| Two-Suited Hand | Two long suits |
| One-Suited Hand | One dominant long suit |
| Freak Hand | Extremely distributional hand |

# Bidding Terminology

| Term | Meaning |
|------|---------|
| Opening Bid | First non-pass bid |
| Response | Partner's first bid after an opening |
| Rebid | Opener's second bid |
| Overcall | Bid after an opponent opens |
| Takeout Double | Double requesting partner to bid |
| Penalty Double | Double intended to defeat the contract |
| Redouble | Doubles a previous double |
| Pass | Declines to bid |
| Cue Bid | Bid of the opponents' suit |
| Jump Bid | Bid that skips one or more levels |
| Free Bid | Bid made without pressure from opponents |
| Forcing Bid | Partner must continue bidding |
| Invitational Bid | Suggests game if partner has extras |
| Sign-Off | Indicates no interest in further bidding |
| Preempt | Weak bid intended to consume bidding space |

# Contract Terminology

| Term | Meaning |
|------|---------|
| Partscore | Contract worth fewer than 100 trick points |
| Game | Contract worth at least 100 trick points |
| Small Slam | Six-level contract |
| Grand Slam | Seven-level contract |

| Redoubled Contract | Contract after a redouble |

| Throw-In | Forcing an opponent to lead favorably |

| Strip | Eliminating side suits before an endplay |

# Memory Guide

## The Language of Bridge

Bridge terminology can be grouped into ten major areas:

1. Cards
2. Suits
3. Hand Types
4. Bidding
5. Contracts
6. Declarer Play
7. Defense
8. Scoring
9. Conventions
10. Tournament Procedures

Learning these categories makes bridge books, software, tournament discussions, and expert commentary much easier to understand.

# Memory Aid

**Bridge Terminology = "Learn the Language, Understand the Game."**

Remember:

- Terminology provides a common language for players around the world.
- Many terms have precise meanings defined by the Laws of Bridge or long-standing expert practice.
- Understanding the vocabulary improves communication, learning, and decision-making.
- Use this document as a thematic reference, and use the **Bridge Glossary** for alphabetical definitions.
- Mastering bridge terminology is one of the fastest ways to improve as both a player and a student of the game.
