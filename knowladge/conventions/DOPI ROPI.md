# DOPI / ROPI Convention

## Purpose

**DOPI** and **ROPI** are conventional responses used when the opponents interfere over your **Blackwood** or **Roman Key Card Blackwood (RKCB)** inquiry.

They allow the partnership to continue exchanging ace or key-card information despite the interference.

- **DOPI** = **Double = 0 (or 3), Pass = 1 (or 4)**
- **ROPI** = **Redouble = 0 (or 3), Pass = 1 (or 4)**

The remaining bids continue to show increasing numbers of key cards.

---

# When It Applies

After your partnership bids:

```
4NT
```

as **Blackwood** or **Roman Key Card Blackwood**

and an opponent interferes.

Examples:

```
4NT
(5♣)
?
```

or

```
4NT
(Double)
?
```

---

# DOPI

## Meaning

**DOPI** stands for:

> **Double = 0 (or 3)**
>
> **Pass = 1 (or 4)**

Used when the opponents **bid a suit** over Blackwood.

---

## Standard Structure

Example:

```
4NT
(5♣)
?
```

| Action | Meaning |
|--------|---------|
| Double | 0 or 3 key cards |
| Pass | 1 or 4 key cards |
| 5♦ | 2 key cards without the trump queen |
| 5♥ | 2 key cards with the trump queen |
| Higher bids | By partnership agreement |

---

## Example

```
South      West
4NT        5♦
Double
```

Shows:

- 0 or 3 key cards.

---

# ROPI

## Meaning

**ROPI** stands for:

> **Redouble = 0 (or 3)**
>
> **Pass = 1 (or 4)**

Used when the opponents **Double** Blackwood.

---

## Standard Structure

Example:

```
4NT
(Double)
?
```

| Action | Meaning |
|--------|---------|
| Redouble | 0 or 3 key cards |
| Pass | 1 or 4 key cards |
| 5♣ | 2 key cards without the trump queen |
| 5♦ | 2 key cards with the trump queen |
| Higher bids | Partnership agreement |

---

# Roman Key Card Version (1430)

When playing **1430 RKCB**, the meanings remain the same.

The interference affects only **how the response is delivered**, not the underlying key-card structure.

Typical mapping:

| Action | Meaning |
|--------|---------|
| Double / Redouble | 0 or 3 key cards |
| Pass | 1 or 4 key cards |
| Cheapest available bid | 2 without the trump queen |
| Next available bid | 2 with the trump queen |

---

# Roman Key Card Version (0314)

If the partnership plays **0314 RKCB**, simply substitute the normal 0314 key-card meanings:

| Action | Meaning |
|--------|---------|
| Double / Redouble | 0 or 3 key cards |
| Pass | 1 or 4 key cards |
| Cheapest available bid | 2 without the trump queen |
| Next available bid | 2 with the trump queen |

The response structure mirrors the partnership's chosen RKCB style.

# Continuations

After the key-card response:

- Ask for the trump queen.
- Cue bid controls.
- Bid the small slam.
- Explore grand slam.

Normal RKCB continuations remain unchanged.

---

# Partnership Agreements

Agree on:

- Whether using **1430** or **0314** RKCB.
- Whether DOPI/ROPI applies only after RKCB or also after standard Blackwood.
- Meaning of higher-level bids after severe interference.
- Queen-ask continuations.
- Whether Pass may be forcing.
- Treatment after two-level interference.

---

# Advantages

- Preserves key-card communication despite interference.
- Easy to remember.
- Compatible with either 1430 or 0314.
- Widely used by expert partnerships.

---

# Disadvantages

- Gives up natural doubles during the sequence.
- Requires complete partnership agreement.
- High-level interference may limit available responses.

---

# Comparison

| Convention | Used After |
|------------|------------|
| DOPI | Opponent bids a suit over Blackwood/RKCB |
| ROPI | Opponent doubles Blackwood/RKCB |
| DEPO | Alternative treatment used by some partnerships |
| PODI | Another less common alternative |

---

# Common Partnership Style

Most expert partnerships play:

- **DOPI** after a suit overcall.
- **ROPI** after a double.
- Works with **Roman Key Card Blackwood (1430)**.
- Normal queen-ask methods continue after the response.

# Memory Aid

**DOPI**

> **D**ouble = **0**
>
> **P**ass = **1**

**ROPI**

> **R**edouble = **0**
>
> **P**ass = **1**

Think:

- **Suit interference → DOPI**
- **Double interference → ROPI**

Both conventions allow the partnership to continue exchanging Blackwood or Roman Key Card information with minimal disruption after the opponents interfere.
