# Lebensohl Convention

## Purpose

Lebensohl is used after partner opens **1NT** and the next opponent makes a **natural 2-level overcall**.

It allows the partnership to distinguish between:

- Weak competitive hands
- Invitational hands
- Game-forcing hands
- Hands with or without a stopper in the opponent's suit

---

# Basic Principle

**2NT is artificial.**

Responder bids **2NT** to force opener to bid **3♣**.

After the forced 3♣ bid, responder clarifies the hand.

Remember:

> **Slow Shows**
>
> Going through 2NT **shows a stopper** in the opponent's suit.

Direct action **denies** a stopper.

---

# Auction

```
1NT   (2X)   ?
```

where 2X is a natural overcall.

---

# Meanings

## Double

Not used.

---

## Pass

No suitable action.

---

## 2NT

Artificial.

Forces opener to bid **3♣**.

May show:

- Weak competitive hand
- Invitational hand
- Game force with stopper

depending on continuation.

---

## New Suit at 3-Level (Direct)

Natural.

Competitive.

Usually invitational or better.

Denies stopper.

---

## New Suit via 2NT

```
1NT (2♠)
2NT Pass
3♣ Pass
3♦
```

Natural.

Weak signoff.

Responder simply wanted to compete.

---

## Cue Bid (Direct)

Example:

```
1NT (2♠)
3♠
```

Stayman.

Game forcing.

Denies stopper.

---

## Cue Bid after 2NT

Example:

```
1NT (2♠)
2NT Pass
3♣ Pass
3♠
```

Stayman.

Game forcing.

Shows stopper.

---

## Direct 3NT

Game values.

Denies stopper.

Opener should continue only with stopper.

---

## 3NT after 2NT

```
1NT (2♠)
2NT Pass
3♣ Pass
3NT
```

Game values.

Shows stopper.

---

# Weak Hands

Example

```
♠ xx
♥ QJxxx
♦ xxx
♣ xxxx
```

Auction

```
1NT (2♠)
2NT Pass
3♣ Pass
3♥
```

Weak signoff.

---

# Invitational Hands

Example

```
♠ xx
♥ KQJxx
♦ AQx
♣ xxx
```

Bid directly at the three level.

---

# Game Force

Use cue bid or 3NT depending on:

- stopper
- major fit
- balanced hand

---

# Memory Aid

| Sequence | Meaning |
|-----------|---------|
| Direct action | No stopper |
| Via 2NT | Stopper |

Remember:

> **Slow Shows**

---

# Example 1

```
North    East    South    West
1NT      2♠      2NT      Pass
3♣       Pass    3♥
```

Weak signoff.

---

# Example 2

```
North    East    South    West
1NT      2♠      3♥
```

Invitational or better.

No spade stopper.

---

# Example 3

```
North    East    South    West
1NT      2♠      3NT
```

Game values.

Requests opener to hold spade stopper.

---

# Example 4

```
North    East    South    West
1NT      2♠      2NT      Pass
3♣       Pass    3NT
```

Game values.

Responder has spade stopper.

---

# Partnership Agreements

Decide:

- Does direct 3-level promise invitational values or game force?
- Is cue bid always Stayman?
- Are transfers still on after interference?
- Do you play Rubensohl instead?

---

# Advantages

- Separates weak and strong hands
- Distinguishes stopper vs. no stopper
- Improves competitive auctions
- Helps locate 3NT and major-suit games

---

# Disadvantages

- Requires partnership memory
- Many partnership variations exist
- Cannot always use transfers after interference

---

# Standard Memory Rule

> **Fast Denies.**
>
> **Slow Shows.**
>
> Going through **2NT** shows a stopper.
