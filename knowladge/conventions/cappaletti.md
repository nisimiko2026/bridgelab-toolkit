# Cappelletti Convention

## Purpose

The **Cappelletti Convention** (also known as **Hamilton** in some regions with slightly different meanings) is a defensive system used **after an opponent opens 1NT**.

Its objectives are to:

- Compete effectively against 1NT.
- Show one-suited and two-suited hands.
- Help partner identify the best contract.
- Disrupt the opponents' communication.

---

# When It Applies

The convention is used after:

```
West   North   East   South
1NT     ? 
```

where the opponent's **1NT opening is natural** (typically 15–17 or 12–14 HCP).

---

# Basic Structure

| Bid | Meaning |
|------|---------|
| Double | Strong balanced hand (penalty or equivalent strength to 1NT opener) |
| 2♣ | Any one-suited hand (6+ card suit) |
| 2♦ | Both majors (5-5 or better) |
| 2♥ | Hearts + a minor |
| 2♠ | Spades + a minor |
| 2NT | Both minors |
| 3-level | Natural preemptive |

---

# Double

Shows:

- Approximately the strength of the opponents' 1NT opening.
- Balanced hand.

Typical range:

- 15-18 HCP (partnership agreement).

Responder usually passes with values or converts to penalty.

---

# 2♣ — One-Suited Hand

Artificial.

Shows:

- Any single long suit.
- Usually six or more cards.

Partner responds:

| Response | Meaning |
|----------|---------|
| 2♦ | Relay asking for the suit |
| Pass | Rare (partnership agreement) |

After the relay:

```
1NT   2♣
Pass  2♦
Pass  2♥
```

Shows a heart suit.

---

# 2♦ — Both Majors

Shows:

- At least 5-5 distribution.
- Hearts and spades.

Partner usually chooses the preferred major.

Example:

```
1NT
2♦
Pass
2♥
```

or

```
2♠
```

---

# 2♥ — Hearts and a Minor

Shows:

- Five or more hearts.
- Five or more clubs or diamonds.

Partner usually:

- Raises hearts.
- Bids 2NT to ask for the minor (optional agreement).

---

# 2♠ — Spades and a Minor

Shows:

- Five or more spades.
- Five or more clubs or diamonds.

Partner chooses the best contract or may ask for the minor.

---

# 2NT — Both Minors

Shows:

- Clubs and diamonds.
- Usually at least 5-5.

Partner selects the preferred minor.

---

# Natural Three-Level Bids

```
3♣
3♦
3♥
3♠
```

Natural.

Preemptive.

Usually seven-card suit.


---

## After 2♥

Responder may:

- Pass
- Raise hearts
- Bid 2NT asking for the minor (if played)
- Bid game

---

## After 2♠

Responder may:

- Pass
- Raise spades
- Bid 2NT asking for the minor (optional)
- Bid game

---

## After 2NT

Responder chooses:

```
3♣
```

or

```
3♦
```

# Partnership Agreements

Decide:

- Is Double for penalty or values?
- Minimum suit quality?
- Is 2NT inquiry used after 2♥ and 2♠?
- Required shape (5-5 or 5-4)?
- Style when vulnerable.
- Continuations after interference.

---

# Advantages

- Covers all common two-suited distributions.
- Simple and easy to remember.
- Makes life difficult for the opponents.
- Frequently finds major-suit fits.
- Effective against both weak and strong 1NT openings.

---

# Disadvantages

- The 2♣ relay gives opponents information.
- Several follow-up methods require partnership agreement.
- Some meanings differ from the Hamilton variation.

---

# Comparison with Hamilton

| Bid | Cappelletti | Hamilton (common version) |
|------|-------------|---------------------------|
| Double | Strong balanced | Penalty |
| 2♣ | Any one-suited hand | Clubs |
| 2♦ | Both majors | Diamonds |
| 2♥ | Hearts + minor | Hearts + minor |
| 2♠ | Spades + minor | Spades + minor |
| 2NT | Both minors | Both minors |

Always confirm which version your partnership plays.

# Memory Aid

|------|---------|
| Double | Strong balanced / penalty (agreement) |
| 2♣ | Any one suit |
| 2♦ | Both majors |
| 2♥ | Hearts + minor |
| 2♠ | Spades + minor |
| 2NT | Both minors |

**Easy mnemonic:**

- **2♣ = One suit**
- **2♦ = Two majors**
- **2♥ = Heart + Minor**
- **2♠ = Spade + Minor**
- **2NT = Two minors**
