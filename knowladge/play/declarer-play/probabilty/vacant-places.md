# Vacant Places

## Overview

**Vacant Places** is a probability principle used in bridge to estimate the location of **missing cards or honors** based on the number of **unknown (vacant) spaces** remaining in each opponent's hand.

Rather than assuming missing cards are equally likely to be in either opponent's hand, the Vacant Places principle recognizes that **a player with more unknown cards is more likely to hold any particular missing card**.

This principle becomes increasingly accurate as declarer counts the defenders' distributions during the play.

The guiding principle is:

> **The more vacant places a defender has, the more likely that defender is to hold any unseen card.**

---

# Purpose

The Vacant Places principle helps players to:

- Locate missing honors.
- Choose the correct finesse.
- Estimate the location of key cards.
- Improve percentage plays.
- Combine probability with counting.
- Reduce unnecessary guessing.

---

# Basic Principle

A **vacant place** is an **unknown card** remaining in a defender's hand.

If one defender has:

```
6 vacant places
```

and the other has:

```
3 vacant places
```

then an unseen card is approximately **twice as likely** to be with the defender who has six vacant places.

---

# Why It Works

Each unknown card must occupy one of the remaining unseen positions.

The greater the number of available positions in one defender's hand, the greater the probability that any particular unseen card is there.

As the play progresses and more cards become known, the number of vacant places changes continuously.

---

# Counting Vacant Places

To calculate vacant places:

1. Determine each defender's original distribution.
2. Subtract all known cards.
3. Count the remaining unknown cards.

Example:

West originally held:

```
5 spades
2 hearts
3 diamonds
3 clubs
```

After several tricks, you know:

- All five spades.
- Both hearts.
- Two diamonds.
- One club.

Remaining unknown cards:

```
Diamond = 1
Clubs = 2

Total vacant places = 3
```

Repeat the process for East.

---

# Example 1 – Choosing a Finesse

Missing honor:

```
♠Q
```

After counting the hand:

West has:

```
6 vacant places
```

East has:

```
3 vacant places
```

The Queen is significantly more likely to be with West.

The percentage play is to finesse against West.

---

# Example 2 – Missing King

Contract

```
3NT
```

Missing:

```
♦K
```

Distribution counting reveals:

West:

```
2 vacant places
```

East:

```
7 vacant places
```

The King is much more likely to be with East.

Declarer adjusts the line accordingly.

---

# Example 3 – Endgame

By Trick 10:

West has:

```
1 vacant place
```

East has:

```
4 vacant places
```

The missing club is four times more likely to be with East.

The Vacant Places principle strongly favors playing East for the missing card.

---

# Relationship to Other Techniques

Vacant Places works best when combined with:

- Counting Distribution.
- Counting High Card Points.
- Restricted Choice.
- Discovery Play.
- Planning the Play.

Together, these techniques produce much more accurate decisions than probability alone.

---

# Planning the Play

Before relying on Vacant Places, ask:

- Have I counted each defender's distribution?
- How many unknown cards remain in each hand?
- Does the auction support this inference?
- Does Restricted Choice apply?
- Is there additional information from the play?

---

# When to Use

Vacant Places is especially valuable when:

- Choosing between two finesses.
- Locating a missing honor.
- Planning a squeeze.
- Deciding whether to play for the drop.
- Solving difficult suit combinations.

---

# Common Mistakes

- Forgetting to update the count after every trick.
- Ignoring the auction.
- Using Vacant Places before counting the distribution.
- Forgetting that probabilities change as the hand develops.
- Ignoring stronger evidence from the play.

---

# Advantages

- Based on sound probability.
- Improves finesse decisions.
- Reduces guessing.
- Becomes more accurate as more cards are revealed.
- Works naturally with distribution counting.

---

# Disadvantages

- Requires accurate counting.
- Provides probabilities, not certainty.
- Can be overridden by bidding or card-play evidence.
- Easy to miscalculate late in the hand.

# Memory Guide

## Five Steps

1. Count the defenders' distribution.
2. Determine the vacant places.
3. Compare the number of unknown cards.
4. Estimate where the missing card is most likely.
5. Combine this with all other available evidence.

# Memory Aid

**Vacant Places = "More Empty Spaces, More Likely the Missing Card Is There."**

Remember:

- **A vacant place is an unknown card remaining in a defender's hand.**
- **The defender with more vacant places is statistically more likely to hold any unseen card.**
- **Update the count after every trick as the number of vacant places changes.**
- **Always combine Vacant Places with the auction, High Card Point counting, and distribution counting.**
- **It is a probability tool—not a guarantee—but it often turns close guesses into sound percentage plays.**

The **Vacant Places** principle is one of the most powerful probability tools in expert bridge. By tracking the number of unknown cards remaining in each defender's hand, declarers and defenders can make more accurate decisions about the location of missing honors and key cards. When combined with counting, Restricted Choice, and information from the auction, Vacant Places becomes an indispensable aid for high-level declarer play and defense.
