# Counting High Card Points (HCP)

## Overview

**Counting High Card Points (HCP)** is one of the most valuable analytical techniques in bridge. Throughout both the auction and the play, expert players continuously estimate **where the missing high cards are located** by accounting for all known high-card points.

Rather than relying on guesswork, players combine information from the **bidding**, **dummy**, **opening lead**, **signals**, and **cards played** to determine which opponent is more likely to hold the missing honors.

Counting HCP is essential for:

- Declarer play
- Defensive play
- Choosing finesses
- Planning squeezes
- Reading the opponents' distribution

The guiding principle is:

> **When you know where the points are, you know where the honors are likely to be.**

---

# Purpose

Counting HCP allows players to:

- Locate missing honors.
- Improve finesse decisions.
- Predict defenders' holdings.
- Interpret the auction accurately.
- Improve declarer planning.
- Strengthen defensive decisions.
- Reduce unnecessary guessing.

---

# High Card Point Scale

The standard HCP scale is:

| Honor | Points |
|--------|--------:|
| Ace | 4 |
| King | 3 |
| Queen | 2 |
| Jack | 1 |

Total HCP in every deal:

```
40
```

---

# Basic Principle

Begin by counting the points you know.

Subtract them from **40**.

The remaining points belong to the opponents.

As more honors appear, continue updating the count.

---

# Example 1 – During the Auction

Auction

```
West      North      East      South
1NT       Pass       3NT       All Pass
```

West's **1NT** opening promises approximately:

```
15–17 HCP
```

Dummy appears with:

```
10 HCP
```

Declarer therefore has approximately:

```
25–27 HCP
```

Only:

```
13–15 HCP
```

remain for both defenders combined.

This immediately narrows the location of missing honors.

---

# Example 2 – During the Play

Dummy

```
♠ AQ
♥ KJ
♦ A
♣ QJ
```

Known HCP:

```
4 + 2 + 3 + 1 + 4 + 2 + 1 = 17 HCP
```

Declarer knows their own hand contains:

```
11 HCP
```

Total known:

```
28 HCP
```

Remaining:

```
12 HCP
```

for the defenders.

As honors appear, declarer updates this total continuously.

---

# Example 3 – Choosing a Finesse

Contract

```
3NT
```

Known HCP:

Declarer + Dummy:

```
28 HCP
```

West opened:

```
1♦
```

East passed throughout.

West is therefore much more likely to hold the missing ♠K than East.

Taking the finesse through West may be the better percentage play.

---

# Counting During the Play

As each honor appears:

Example:

West shows:

```
♣A
♦K
♥Q
```

West has revealed:

```
9 HCP
```

If West's bidding suggested about 11 HCP, only about 2 HCP remain hidden.

This helps locate the remaining honors.

---

# Using the Auction

The auction provides major clues.

Examples:

### Opening Bid

An opening bid usually promises at least:

```
12 HCP
```

### 1NT Opening

Typically:

```
15–17 HCP
```

### Weak Two

Usually:

```
5–10 HCP
```

### Strong 2♣

Generally:

```
22+ HCP
```

These ranges allow accurate estimates before the opening lead.

---

# Combining HCP with Distribution

High-card counting is strongest when combined with:

- Distribution counting.
- Suit lengths.
- Opening lead analysis.
- Signals.
- False cards.

Expert players use **both HCP and shape** to locate missing honors.

---

# Declarer Applications

Declarer uses HCP counting to:

- Choose between two finesses.
- Decide whether to finesse or play for the drop.
- Plan Discovery Play.
- Evaluate squeeze possibilities.
- Predict dangerous defenders.

---

# Defensive Applications

Defenders use HCP counting to:

- Locate declarer's honors.
- Predict dummy's remaining strength.
- Choose opening leads.
- Decide whether partner holds missing honors.
- Avoid unnecessary finesses by declarer.

---

# Common Mistakes

- Forgetting to update the count.
- Ignoring the auction.
- Counting only visible honors.
- Forgetting already-played honors.
- Ignoring distributional clues.

---

# Planning the Hand

Before Trick One, ask:

- How many HCP do I know?
- How many remain unknown?
- Which opponent is more likely to hold them?
- Does the bidding confirm this?
- How does this affect my line of play?

---

# Advantages

- Reduces guesswork.
- Improves finesse decisions.
- Helps locate missing honors.
- Supports Discovery Play.
- Essential for expert-level bridge.

---

# Disadvantages

- Requires continuous counting.
- Distribution may outweigh HCP in some positions.
- Bidding ranges are estimates, not exact values.
- False carding may create misleading impressions.

# Player's Checklist

Before making a key decision:

- How many HCP are known?
- How many remain unknown?
- Which opponent is more likely to hold the missing honors?
- Does the auction support my conclusion?
- Have any honors already appeared?

# Memory Guide

## Five Steps

1. Count your HCP.
2. Count dummy's HCP.
3. Estimate opponents' HCP from the auction.
4. Update the count after every honor played.
5. Use the information to guide critical decisions.

# Memory Aid

**Counting HCP = "The Missing Points Tell the Story."**

Remember:

- **There are always exactly 40 HCP in the deck.**
- **Use the auction to estimate where the points are.**
- **Update your count whenever an honor appears.**
- **Combine HCP counting with distribution for the most accurate picture.**
- **Expert players rarely guess—they count.**

Counting High Card Points is one of the foundations of expert bridge. Whether deciding on a finesse, planning a squeeze, defending a contract, or interpreting the auction, the ability to account for the location of every high-card point transforms uncertain guesses into logical, high-percentage decisions.
