# 2/1 Game Forcing (2/1 GF)

## Purpose

The **2/1 Game Forcing (2/1 GF)** system is a modern bidding method in which a **two-level response in a new suit** to a **one-level major opening** creates a **game force**.

The system allows the partnership to:

- Accurately describe balanced and unbalanced hands.
- Investigate slam with more bidding space.
- Differentiate between invitational and game-forcing hands.
- Improve game and slam bidding accuracy.

Today, 2/1 GF is the standard system played by most expert partnerships.

---

# Basic Principle

After partner opens:

```
1♥
```

or

```
1♠
```

an uncontested response of:

```
2♣
2♦
2♥ (after 1♠)
```

is **Game Forcing**.

The partnership **may not stop below game** unless there is an exceptional reason (for example, a significant misfit).

---

# Requirements

A 2/1 response normally promises:

- 12+ HCP
- Good five-card suit (occasionally a strong four-card suit by agreement)
- No immediate support raise available
- Sufficient strength for game

| 1♥ | 2♦ | Game Force |
| 1♠ | 2♣ | Game Force |
| 1♠ | 2♦ | Game Force |
| 1♠ | 2♥ | Game Force |

# What Is NOT 2/1?

The following are **not** game forcing:

```
1♦
2♣
```

Natural.

Usually invitational.

---

```
1♣
2♦
```

Natural.

Not 2/1.

# Forcing 1NT

An important companion convention.

After:

```
1♥
```

or

```
1♠
```

Responder may bid:

```
1NT
```

Artificial.

Usually shows:

- 6-11 HCP
- Not enough for a 2/1 response
- Any balanced hand
- Weak hand with long suit
- Invitational hands without a convenient natural bid

The bid is **forcing for one round**.

---

# Opener's Rebids after Forcing 1NT

Priority:

1. Show second suit.
2. Rebid six-card major.
3. Rebid notrump.
4. Raise responder if appropriate.

Examples:

```
1♠
1NT
2♣
```

Natural.

---

```
1♥
1NT
2♥
```

Shows six hearts.

---

# Opener's Rebids after a 2/1 Response

General priorities:

- Describe shape.
- Show minimum or extra values.
- Delay notrump when possible.
- Cooperate toward slam.

Examples:

```
1♠
2♣
2♦
```

Natural.

---

```
1♥
2♦
2NT
```

Balanced minimum.

---

```
1♠
2♥
3♣
```

Natural second suit.

---

# Balanced Hands

With balanced minimum:

```
1♠
2♣
2NT
```

Shows:

- Balanced
- Approximately 12-14 HCP (partnership agreement)

---

# Reverse Bids

Example:

```
1♦
1♠
2♥
```

Natural.

Strong.

Normally forcing for one round.

---

# Jump Rebids

Jump rebids show extras.

Example:

```
1♠
2♣
3♠
```

Extra playing strength.

Usually six-card suit.

---

# Fourth Suit Forcing

Example:

```
1♥
2♣
2♦
2♠
```

Artificial.

Usually requests further description.

Often denies a natural spade suit.

---

# Splinter Raises

Many 2/1 partnerships include splinters.

Example:

```
1♠
4♣
```

Shows:

- Four-card spade support
- Singleton or void clubs
- Game force

# Advantages

- Excellent slam exploration.
- Accurate game bidding.
- Describes shape naturally.
- Conserves bidding space.
- Modern expert standard.

---

# Disadvantages

- Requires many partnership agreements.
- More memory than Standard American.
- Some invitational auctions become artificial.

# System Summary

### Opening Requirements

- Five-card majors
- Better minor
- 15-17 1NT (typical)

### Core Principles

- **Any uncontested 2/1 response to a major opening is Game Forcing.**
- **1NT is forcing for one round.**
- **Natural bidding whenever possible.**
- **Slow arrival generally shows extra strength.**
- **Game is never bypassed after a 2/1 response.**

---

# Memory Aid

**2/1 = Game Force**

Remember these three rules:

1. **Two over One = Game Force**
2. **1NT = Forcing**
3. **Describe shape before strength**

These three principles form the foundation of the modern 2/1 bidding system.
