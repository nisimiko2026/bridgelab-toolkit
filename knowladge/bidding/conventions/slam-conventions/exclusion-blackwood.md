# Exclusion Blackwood (Voidwood)

## Purpose

**Exclusion Blackwood**, often called **Voidwood**, is a slam-investigation convention used when one partner has a **known void**. It asks partner for the number of **key cards excluding the Ace of the void suit**.

Unlike ordinary **Roman Key Card Blackwood (RKCB)**, Exclusion Blackwood ignores the ace of the void suit because that ace has no value opposite a void.

The convention helps the partnership:

- Investigate slam accurately with a void.
- Avoid overvaluing the ace of the void suit.
- Preserve bidding space.
- Improve grand slam decisions.

---

# When It Applies

Exclusion Blackwood is used when:

- A trump suit has been agreed.
- One partner has shown or possesses a known void.
- Slam is under consideration.

The bid is a **jump to the void suit above game**.

---

# Basic Principle

A jump into a void suit asks:

> **"Ignoring the Ace of this suit, how many key cards do you hold?"**

The excluded ace is **not counted**.

---

# Example

Trump:

```
♠
```

Responder has:

- A void in diamonds.

Auction:

```
1♠
3♠
5♦
```

The bid of:

```
5♦
```

is **Exclusion Blackwood**.

It asks for key cards **excluding the ♦A**.

---

# Which Bid Is Exclusion?

After a trump suit has been agreed:

| Bid | Meaning |
|------|---------|
| Jump into a void suit | Exclusion Blackwood |
| 4NT | Normal RKCB |

Example:

Trump = Hearts

```
1♥
3♥
5♣
```

5♣:

Exclusion Blackwood.

---

# Responses (1430 Style)

Most expert partnerships retain their normal **1430** structure.

Ignoring the excluded ace:

| Response | Key Cards |
|----------|-----------|
| Cheapest step | 1 or 4 |
| Second step | 0 or 3 |
| Third step | 2 without trump queen |
| Fourth step | 2 with trump queen |

---

# Responses (0314 Style)

If the partnership plays **0314 RKCB**, the same principle applies.

The excluded ace is ignored.

Response steps follow the partnership's agreed RKCB structure.

---

# Continuations

After the response:

The partnership may:

- Ask for the trump queen.
- Cue bid further controls.
- Bid a small slam.
- Explore a grand slam.

Normal RKCB continuations apply.

---

# What Exclusion Blackwood Does NOT Ask

It does **not** ask about:

- The ace of the void suit.
- Number of kings.
- Controls generally.
- Trump length.

It asks only for:

**Key cards excluding one ace.**

---

# When NOT to Use

Avoid Exclusion Blackwood:

- Without a known void.
- Before agreeing trumps.
- When ordinary RKCB is sufficient.
- When partner may misinterpret the jump as natural.

---

# Partnership Agreements

Agree on:

- Which jumps are Exclusion.
- 1430 or 0314 response structure.
- Whether voids must be previously shown.
- Queen-ask continuations.
- Grand slam continuations.
- Responses after interference.
- DOPI/ROPI after Exclusion.

---

# Advantages

- Much more accurate than RKCB with a void.
- Eliminates the useless ace.
- Excellent for grand slam decisions.
- Widely used by expert partnerships.
- Integrates naturally with RKCB.

---

# Disadvantages

- Artificial.
- Requires precise partnership agreement.
- Can be confused with natural control bids.

---

# Comparison

| Convention | Purpose |
|------------|---------|
| Blackwood | Count aces |
| RKCB | Count key cards |
| Exclusion Blackwood | Count key cards except one ace |
| Gerber | Ask for aces after notrump |
| DOPI/ROPI | Handle interference over RKCB |

---

# Common Partnership Style

Most expert partnerships play:

- **Jump into a void suit = Exclusion Blackwood.**
- Uses normal **1430 RKCB** responses.
- The excluded ace is ignored.
- Queen-ask structure remains unchanged.
- DOPI/ROPI after interference.

---

# Memory Guide

### Ask

Jump into your void suit.

Example:

```
5♦
```

Void in diamonds.

---

### Partner Responds

Ignoring:

```
♦A
```

Use normal RKCB response steps.

---

# Typical Sequence

```
1♠
3♠
5♦
5♥
5NT
6♣
```

Meaning:

- Exclusion Blackwood.
- One (or four) key cards excluding ♦A.
- Continue slam investigation.

---

# Relationship with Other Slam Conventions

Typical expert slam sequence:

1. Agree trump.
2. Cue Bid controls.
3. Serious 3NT.
4. Last Train.
5. Exclusion Blackwood (if void).
6. RKCB continuations.
7. Grand slam investigation.

---

# Memory Aid

**Exclusion Blackwood = "Ignore My Void."**

Remember:

- **Jump into the void suit.**
- **Ignore the ace of that suit.**
- **Ask for the remaining key cards.**
- **Use normal RKCB response steps.**
- **Only after trump has been agreed.**

Exclusion Blackwood is one of the most powerful expert slam conventions. By excluding the ace opposite a known void, it produces significantly more accurate slam decisions than ordinary Blackwood or RKCB whenever a void is present.
