# Long Suit Game Try (LSGT)

## Definition

A **Long Suit Game Try (LSGT)** is a **natural game invitation** made after a major-suit fit has been established, in which opener bids a **new suit to show length and potential trick-taking power in that suit**, while inviting partner to bid game if they hold suitable fitting values.

Unlike a **Help Suit Game Try**, where opener asks for help in a weak suit, a Long Suit Game Try says:

> **"I have a strong side suit that may produce extra tricks if you have useful support for it."**

Responder evaluates whether the side suit is likely to become a source of tricks.

---

# Purpose

The convention helps determine whether the partnership should:

- Stop in a partscore.
- Continue to game.
- Exploit a promising long side suit.
- Evaluate fitting values rather than simply HCP.

Its objective is to discover whether the partnership has enough **playing strength** to justify bidding game.

---

# Philosophy

Long Suit Game Tries are based on one important principle:

> **Long suits produce tricks.**

High-card points alone do not determine whether game is successful.

Instead, success often depends on:

- establishing long suits,
- developing extra winners,
- eliminating losers,
- creating entries.

A long side suit frequently becomes the deciding factor.

---

# Historical Background

Before sophisticated hand evaluation became common, many partnerships invited game simply by bidding:

```
1♠
2♠
3♠
```

or

```
1♥
2♥
3♥
```

These invitations communicated little beyond extra strength.

Natural game-try methods gradually evolved.

Two schools emerged:

1. Help Suit Game Try
2. Long Suit Game Try

Some partnerships preferred to identify weakness.

Others preferred to identify a potential source of tricks.

Today both methods remain popular.

# Advanced Philosophy

The Long Suit Game Try is based on one of the oldest principles in bridge:

> **Long suits produce tricks.**

Unlike Help Suit Game Tries, which focus on solving a weakness, Long Suit Game Tries focus on **creating winners**.

Expert declarers constantly ask:

- Can my side suit be established?
- Will it provide discards?
- Can I eliminate losers?
- Are sufficient entries available?
- Can partner help establish the suit?

These questions determine whether game is likely to succeed.

---

# Offensive Evaluation

Long Suit Game Tries emphasize **offensive potential**.

Responder should evaluate

- source of tricks,
- transportation,
- timing,
- entries,
- side-suit support,
- trump control.

This differs from defensive evaluation, which emphasizes quick tricks and controls.

---

# Establishing Long Suits

A long suit becomes valuable when:

- defenders' high cards are driven out,
- the suit breaks favorably,
- declarer retains entries,
- sufficient length remains.

Example

```
AQJ109
```

may eventually produce four or five winners.

---

# Suit Establishment

Experts estimate

- how many rounds the suit requires,
- whether transportation exists,
- whether opponents can attack trumps first.

Example

```
AQJ987
```

may require two losing rounds before becoming productive.

Responder should judge whether enough entries remain.

---

# Entries

Entries are often more valuable than an extra Queen.

Example

Opener

```
♦ AQJ987
```

Responder

```
♦ K4
```

The King not only strengthens the suit but also creates an additional entry.

Without entries,

the long suit may never be cashed.

---

# Transportation

Responder should evaluate

- side entries,
- trump entries,
- timing entries,
- communication between hands.

Poor transportation frequently defeats otherwise excellent games.

# Long Suit Game Try (LSGT)

# Part 5 – Expert Recommendations, FAQs, Summary and Reference

---

# Expert Recommendations

Expert partnerships do not evaluate a Long Suit Game Try by counting
high-card points alone.

Instead, they ask:

- Will the long suit become established?
- Can declarer reach the suit?
- Does responder hold fitting honors?
- Are there enough entries?
- Will trump control be maintained?
- Can the side suit provide discards?
- Does the partnership have sufficient offensive potential?

The emphasis is always on **trick-taking ability**, not merely HCP.

---

# Evaluating Long Suits

Not all five-card suits are equal.

Experts evaluate:

- Honor strength
- Intermediate cards
- Suit texture
- Number of losers
- Ease of establishment
- Available entries

For example

Excellent

```
AKQ109
```

Very Good

```
AQJ98
```

Good

```
KQ1097
```

Marginal

```
AJ876
```

Poor

```
J9876
```

Length alone does not justify a Long Suit Game Try.

---

# When Not to Use LSGT

Avoid a Long Suit Game Try when:

- Opener has a minimum opening.
- Game is already certain.
- The side suit is weak.
- There are insufficient entries.
- The hand is completely balanced with no offensive potential.
- Partnership agreements call for another method.

## IMPs

# Frequently Asked Questions

## Does the trial suit promise five cards?

Usually.

Some partnerships occasionally allow a very strong four-card suit.

---

## Does it promise a second suit?

No.

The bid is made because the suit is expected to become a source of tricks.

---

## Does responder simply count HCP?

No.

Responder evaluates:

- fitting honors,
- entries,
- trump quality,
- distribution,
- offensive potential.

---

## Is a singleton valuable?

Usually not in the trial suit itself.

However,

shortness elsewhere may create ruffing value.

---

## Should responder upgrade side-suit honors?

Only when they improve opener's long suit.

Honors in unrelated suits may contribute little.

---

## Is LSGT forcing?

No.

Responder chooses between:

```
3♥ / 3♠
```

or

```
4♥ / 4♠
```

according to the agreed trump suit.

---

## Can opener continue after responder bids game?

Normally no.

The invitation has been accepted.

Further bidding generally requires exceptional agreements or slam interest.

# Summary

The **Long Suit Game Try** is an invitational bidding method used after a
major-suit fit has been established to show that opener possesses a
promising **long side suit** capable of producing additional tricks.

Unlike the Help Suit Game Try, which asks partner to strengthen a weak
suit, the Long Suit Game Try identifies a **source of tricks**.

Responder evaluates:

- support for the long suit,
- entries,
- trump quality,
- controls,
- distribution,
- offensive potential.

The convention is particularly effective with distributional hands and
helps partnerships distinguish between games that rely on high-card
strength and those that rely on **establishing long suits**.

---

# Key Points

- A Long Suit Game Try is an invitational bid made after a major-suit fit has been established.
- The trial suit shows a **long, potentially productive side suit**, not weakness.
- The convention focuses on **offensive trick-taking potential**.
- Suit quality is as important as suit length.
- Entries are often critical to establishing the long suit.
- Responder evaluates fitting honors, trump quality, controls, and distribution.
- Partnership agreements must define suit quality, minimum length, and continuations.
- Long Suit Game Tries are commonly compared with Help Suit, Short Suit, Two-Way, and Maximal Game Tries.
- The convention rewards realistic hand evaluation based on **playing strength rather than raw HCP**.
