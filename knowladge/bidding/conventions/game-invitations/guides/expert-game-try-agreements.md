# Expert Game Try Agreements

## Purpose

This document presents a **recommended partnership agreement** for advanced
tournament partnerships.

It is **not** a bridge convention.

Instead, it describes a coherent set of agreements that integrates the best
modern Game Try methods into one partnership style.

The objective is

- minimize misunderstandings,
- maximize descriptive accuracy,
- maintain consistency across all auctions.

---

# Partnership Philosophy

Expert partnerships should strive for

- simple rules,
- consistent meanings,
- minimal ambiguity,
- logical continuations.

Every Game Try should answer one question:

> **"What information does partner need to decide whether game is correct?"**

---

# General Principles

## Principle 1

Use the **simplest available method** that accurately describes the hand.

---

## Principle 2

Avoid unnecessary artificial methods.

Natural descriptions are preferable whenever they solve the problem.

---

## Principle 3

Reserve artificial methods for auctions where they provide a genuine advantage.

---

## Principle 4

Every agreement should be documented on the convention card.

---

# Recommended Agreements

## Help Suit Game Try

Use

- natural bids,
- suit asking for help,
- lowest economical bid.

Avoid hidden meanings.

---

## Long Suit Game Try

Use

- natural long suit,
- source of tricks,
- five-card or longer suit.

Responder evaluates

- honors,
- entries,
- controls.

---

## Short Suit Game Try

Use

- singleton,
- void,
- shortage.

Responder upgrades

- ruffing values,
- trump support.

Downgrade

- wasted honors opposite shortage.

---

## Maximal Game Try

Always play

Maximal Game Try

after competitive interference.

Example

```
1♠
Pass
2♠
3♣
4♣*
```

Artificial.

Game invitation.

---

Do **not**

attempt Help Suit Game Tries after interference.

---

## Two-Way Game Try

If played,

use

one structure consistently.

Do not alternate between different expert treatments.

---

## Artificial Game Tries

Only if

- partnership practices regularly,
- written agreements exist,
- relay structure is well understood.

---

## Artificial 2NT

Use only

- after uncontested auctions,
- with complete partnership agreements.

---

# Recommended Partnership Style

## Natural Whenever Possible

Natural descriptions reduce memory load.

Artificial methods should solve problems,

not create them.

---

## One Meaning Per Bid

Avoid

one bid having multiple unrelated meanings.

Consistency improves partnership confidence.

---

## No Optional Meanings

Avoid agreements such as

> "Sometimes natural."

> "Sometimes artificial."

Expert partnerships prefer

one meaning,

every time.

---

# Hand Evaluation

Responder should evaluate

- trump quality,
- controls,
- distribution,
- offensive values,
- Losing Trick Count,
- working honors.

High Card Points alone are insufficient.

---

# Trump Quality

Upgrade

```
KJ10x

QJ10x

AKxx
```

Downgrade

```
Qxxx

xxxx
```

---

# Controls

Upgrade

- Aces,
- Kings,
- singleton,
- void.

Controls frequently determine whether game succeeds.

---

# Distribution

Upgrade

- fifth trump,
- sixth trump,
- singleton,
- void,
- double fit.

---

# Wasted Values

Downgrade

- unsupported queens,
- honors opposite known shortness,
- duplicated values.

# Summary

A strong expert partnership does not attempt to play every available Game Try.

Instead, it selects a logical, consistent set of agreements that

- cover natural auctions,
- handle competitive auctions,
- evaluate hands accurately,
- minimize misunderstandings.

The recommended progression is

- Help Suit,
- Long Suit,
- Short Suit,
- Maximal,
- Two-Way,

with Artificial and Artificial 2NT added only when both partners are fully
comfortable with the additional complexity.

Consistency is more important than sophistication.
