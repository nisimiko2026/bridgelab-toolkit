# Simple Game Try Agreements

## Purpose

This guide presents a **simple, practical set of partnership agreements** for
players who want effective Game Try methods without the complexity of advanced
relay systems.

The objective is to

- keep bidding natural,
- minimize memory requirements,
- avoid misunderstandings,
- improve game decisions.

For most club partnerships, these agreements are more than adequate.

---

# Partnership Philosophy

A simple partnership should emphasize

- natural bidding,
- consistency,
- easy memory,
- sound judgment.

The partnership should not attempt to play every available Game Try.

Instead,

play a few methods well.

---

# Recommended Convention Set

Play only the following Game Try methods.

✓ Help Suit Game Try

✓ Long Suit Game Try

✓ Maximal Game Try

Optional

✓ Short Suit Game Try

Do **not** play

- Artificial Game Tries
- Artificial 2NT
- Relay structures
- Complex Two-Way methods

unless both partners study them thoroughly.

---

# Primary Agreements

## Help Suit Game Try

This should be the partnership's main Game Try.

Use

- the cheapest available suit,
- naturally,
- asking partner for help.

Example

```
1♠
2♠
3♣
```

Meaning

> "I have extra values and need help in clubs."

---

## Long Suit Game Try

Use when holding

- a strong five-card or longer side suit
- that may produce additional tricks.

Responder evaluates

- honors,
- entries,
- fit with the long suit.

---

## Short Suit Game Try (Optional)

Play this only if

both partners understand

- singleton evaluation,
- wasted values,
- ruffing potential.

Otherwise,

do not include it.

---

## Maximal Game Try

Always use

Maximal Game Try

after opponents compete.

Example

```
1♥
Pass
2♥
3♦
4♦*
```

Artificial.

Invitational.

This avoids guessing after bidding space has been reduced.

---

# Agreements Not Recommended

For most club partnerships,

avoid

- Artificial 2NT,
- relay responses,
- complicated continuations,
- multiple optional meanings,
- partnership-dependent relay structures.

The additional complexity usually outweighs the practical gain.

---

# Hand Evaluation

Responder should evaluate

## Trump Support

Upgrade

- four-card support,
- five-card support,
- strong intermediates.

---

## Controls

Upgrade

- Aces,
- Kings.

Queens alone rarely justify accepting a marginal invitation.

---

## Distribution

Upgrade

- singleton,
- void,
- fifth trump.

---

## Working Honors

Good honors

- supporting opener's long suit,
- outside opener's short suit.

Poor honors

- unsupported queens,
- honors opposite known shortage.

---

# Simple Upgrade Rules

Upgrade

✓ Fifth trump

✓ Good trump honors

✓ Singleton

✓ Void

✓ Two Aces

---

Downgrade

✓ Flat hand

✓ Weak trumps

✓ Unsupported Queens

✓ Duplicate values

# Competition

| Situation | Agreement |
|-----------|-----------|
| No interference | Normal Game Try |
| Opponents compete | Maximal Game Try |
| Very high-level competition | Use judgment |

Keep the agreement simple.

---

# Partnership Checklist

Before beginning play,

confirm that both partners agree on

✓ What a Help Suit Game Try means.

✓ When Long Suit Game Tries are used.

✓ Whether Short Suit Game Tries are played.

✓ That Maximal Game Try applies after interference.

If either partner is uncertain,

review the agreement before play.

# Memory Tips

Remember only four basic ideas.

## Help Suit

"I need help."

---

## Long Suit

"I have a source of tricks."

---

## Short Suit

"I have ruffing potential."

---

## Maximal

"We lost bidding space."

---

If you remember these four ideas,

you will correctly handle the great majority of Game Try auctions.

---

# Recommended Learning Progression

Begin with

1. Help Suit

After becoming comfortable,

add

2. Long Suit

Next,

3. Maximal

Finally,

4. Short Suit

Only after mastering these methods should a partnership consider

- Two-Way Game Tries,
- Artificial Game Tries,
- Artificial 2NT.

---

# Common Mistakes

Avoid

- playing conventions not discussed,
- changing agreements during play,
- using artificial bids without documentation,
- evaluating only High Card Points,
- forgetting that trump quality matters.

---

# Advantages of This Agreement Set

- Easy to remember.
- Almost entirely natural.
- Suitable for occasional partnerships.
- Covers nearly every common Game Try auction.
- Requires very little convention-card space.
- Easily expanded in the future.

---

# When to Upgrade

As the partnership gains experience,

consider adding

1. Short Suit Game Tries.

Later,

2. Two-Way Game Tries.

Finally,

3. Artificial 2NT,

only if both partners are willing to practice regularly.

---

# Recommended Partnership

This agreement package is ideal for

- beginning duplicate players,
- club partnerships,
- occasional partnerships,
- social bridge,
- teaching programs,
- improving intermediate players.

It provides an excellent balance between simplicity and effectiveness.

For most partnerships,

the following package offers the best balance between memory and performance.

| Convention | Recommendation |
|------------|:--------------:|

| Long Suit Game Try | ✓ Recommended |
| Maximal Game Try | ✓ Essential |
| Short Suit Game Try | Optional |
| Two-Way Game Try | Later |

good game decisions in the overwhelming majority of practical situations.
