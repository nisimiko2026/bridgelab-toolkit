# Passed-Hand Jacoby

## Overview

**Passed-Hand Jacoby** is an expert partnership treatment that extends the
principles of **Jacoby 2NT** to auctions where responder is a **passed hand**.

Unlike standard **Jacoby 2NT**, which is **game forcing**, a Passed-Hand Jacoby
shows

- excellent support for opener's major,
- constructive values,
- game interest,
- but insufficient strength for a game force because responder has already
  passed.

It allows responder to distinguish balanced constructive raises from Passed-Hand
Splinters, which additionally show shortness.

---

# Objectives

Passed-Hand Jacoby enables responder to

- show four-card or better trump support,
- describe constructive values,
- invite game accurately,
- distinguish balanced hands from splinter hands,
- preserve bidding space,
- improve opener's hand evaluation.

---

# Why Use the Convention?

After

```
Pass
Pass
1♠
?
```

the partnership already knows responder lacks an opening bid.

Without a special agreement, responder often cannot distinguish between

- a simple constructive raise,
- an invitational raise,
- an excellent fitting hand,
- a hand with shortness.

Passed-Hand Jacoby fills this gap.

---

# Basic Principle

Typical auction

```
Pass
Pass
1♥
2NT*
```

shows

- passed hand,
- four-card or better heart support,
- constructive values,
- game invitation,
- no singleton or void.

The bid is artificial.

---

# Requirements

Typical expert requirements

- previously passed hand,
- four-card or longer trump support,
- approximately 9–11 support points,
- balanced or semi-balanced distribution,
- no significant shortness.

Some partnerships allow five-card support.

---

# Hand Evaluation

Evaluation is based on

- support points,
- Losing Trick Count,
- playing strength,
- offensive potential.

Distribution remains important, although balanced hands are the most common.

# Difference from Standard Jacoby 2NT

Standard Jacoby

```
1♥
2NT*
```

shows

- opening values,
- game force,
- slam interest possible.

Passed-Hand Jacoby

```
Pass
Pass
1♥
2NT*
```

shows

- constructive values,
- invitation to game,
- not forcing to game.

---

# Difference from Passed-Hand Splinter

Passed-Hand Jacoby

- balanced,
- no singleton,
- constructive values.

Passed-Hand Splinter

- singleton or void,
- stronger offensive shape,
- distributional evaluation.

Opener evaluates

- controls,
- trump quality,
- wasted values,
- playing strength,
- distribution.

Typical continuations include

- minimum rebid,
- game acceptance,
- descriptive natural rebids,
- cue bids with exceptional hands.

# Vulnerability

Passed-Hand Jacoby is only slightly affected by vulnerability.

Unlike preemptive raises, it remains primarily constructive.

---

# Competition

After interference

```
Pass
Pass
1♠
(2♦)
?
```

partnership agreement determines whether

- 2NT remains Jacoby,
- doubles replace the convention,
- cue bids substitute.

Many expert partnerships suspend the treatment after significant interference.

---

# Slam Interest

Responder has denied an opening hand.

Consequently,

slam interest is uncommon,

although opener may continue investigating with an exceptional hand opposite an
excellent fit.

---

# Expert Style

Modern tournament partnerships frequently combine

- Drury,
- Reverse Drury,
- Passed-Hand Jacoby,
- Passed-Hand Splinter,

to distinguish every constructive passed-hand raise.

This creates a highly descriptive raising structure.

# Expert Recommendations

A common expert structure after a passed hand is

| Bid | Meaning |
|------|---------|
| Simple Raise | Weak constructive |
| Drury | Constructive inquiry |
| Reverse Drury | Strong constructive raise |
| Passed-Hand Jacoby | Invitational raise without shortness |
| Passed-Hand Splinter | Invitational raise with shortness |

This framework allows responder to describe virtually every type of supporting
hand while helping opener judge whether game is worthwhile.

---

# Modern Expert Notes

Many world-class partnerships do **not** include Passed-Hand Jacoby as a
standard convention. Instead, they use **Drury**, **Reverse Drury**, and
**Passed-Hand Splinters**, relying on natural rebids for other invitational
hands.

Partnerships that adopt Passed-Hand Jacoby do so to achieve greater precision,
particularly in systems that emphasize complete differentiation among all
constructive raises. As with many advanced conventions, its effectiveness
depends on detailed partnership agreements and consistent application.

---

# Summary

**Passed-Hand Jacoby** is an advanced partnership treatment that extends the
ideas of **Jacoby 2NT** to passed-hand auctions. It shows **strong trump
support**, **constructive invitational values**, and **no significant
shortness**, enabling opener to evaluate game prospects accurately without
committing the partnership to game.

Although not universally played, it fits naturally into modern expert raising
structures alongside **Drury**, **Reverse Drury**, and **Passed-Hand
Splinters**, providing a comprehensive and highly descriptive framework for
constructive passed-hand auctions.
