# Inverted Minors

## Overview

**Inverted Minors** is a modern constructive bidding convention in which the
meanings of the **single raise** and **double raise** of partner's minor-suit
opening are exchanged.

Instead of

```
1♦ — 2♦
```

being weak,

it becomes **strong, constructive, and usually forcing for one round**.

Conversely,

```
1♦ — 3♦
```

becomes a **preemptive raise**.

The same treatment applies after a **1♣** opening.

Inverted Minors allow partnerships to investigate game and slam efficiently
while reserving the jump raise for obstructive purposes.

---

# Objectives

The convention aims to

- distinguish constructive and preemptive raises,
- improve game exploration,
- preserve bidding space,
- identify balanced and unbalanced hands,
- facilitate slam investigation,
- increase competitive pressure.

---

# Basic Principle

Without the convention

```
1♦ — 2♦
```

is weak,

while

```
1♦ — 3♦
```

shows invitational strength.

With Inverted Minors

```
1♦ — 2♦
```

becomes

- constructive,
- approximately 10+ support points,
- four-card support or better,
- forcing for one round.

while

```
1♦ — 3♦
```

becomes

- weak,
- preemptive,
- approximately 0–7 support points,
- five-card support (usually).

---

# Applicability

The convention applies after

```
1♣
```

and

```
1♦
```

openings.

It normally applies only when

- opponents pass,
- opener's bid is natural,
- responder has adequate support.

Partnership agreements vary after interference.

---

# Requirements

Typical requirements include

- four-card support or better,
- approximately 10+ support points,
- no four-card major requiring immediate introduction,
- constructive intentions.

Some partnerships require

- 10–12 HCP,

while others evaluate using

- support points,
- Losing Trick Count,
- playing strength.

---

# Support Evaluation

Support is evaluated using

- High Card Points,
- distribution,
- trump length,
- shortness,
- suit quality.

Typical upgrades include

- singleton,
- void,
- fifth trump,
- excellent intermediates.

---

# Basic Response Structure

After

```
1♣
```

Responder bids

```
2♣
```

showing

- constructive raise,
- four or more clubs,
- game interest.

After

```
1♦
```

Responder bids

```
2♦
```

showing the same values.

Jump raises become preemptive.

---

# Point Ranges

Typical expert style

| Response | Meaning |
|----------|---------|
| Single Raise | 10+ support points, forcing one round |
| Jump Raise | Weak preemptive raise |
| 1NT | Balanced hand without sufficient support |
| New Suit | Natural |

Exact ranges vary.

---

# Why Use Inverted Minors?

Traditional raises create several problems.

Example

```
1♦ — 2♦
```

may conceal

- invitational values,
- game values,
- slam interest.

Inverted Minors immediately identify constructive hands while preserving room
for exploration.

---

# Advantages

The convention provides

- excellent constructive bidding,
- improved slam investigation,
- efficient use of bidding space,
- stronger competitive auctions,
- accurate hand description.

---

# Disadvantages

The convention

- requires partnership agreement,
- changes standard meanings,
- complicates competitive auctions,
- requires discussion after interference.

---

# Opener's Rebids

After the constructive raise,

opener continues naturally.

Possible rebids include

- minimum rebid,
- notrump,
- new suit,
- game invitation,
- cue bid,
- control showing,
- slam exploration.

The auction remains forcing for one round.

---

# Minimum Opener

Example

```
1♦
2♦
Pass?
```

Opener **may not pass**.

Typical continuation

```
1♦
2♦
2NT
```

Minimum balanced opener.

---

# Strong Opener

Example

```
1♣
2♣
2♥
```

Shows

- extra values,
- heart suit,
- constructive continuation.

---

# Balanced Hands

Balanced openers frequently rebid

```
2NT
```

or

```
3NT
```

depending upon

- strength,
- stoppers,
- partnership agreements.

---

# Unbalanced Hands

Unbalanced openers frequently

- rebid a second suit,
- reverse,
- jump,
- show singleton,
- begin control bidding.

---

# Major Suit Considerations

Most partnerships **do not** use Inverted Minors when responder holds a
four-card major that should be introduced first.

Example

```
♠ QJ84
♥ K6
♦ J764
♣ KQ8
```

After

```
1♦
```

Responder bids

```
1♠
```

not

```
2♦
```

Locating a major-suit fit remains the priority.

---

# Partnership Agreements

Partners should define

- minimum point range,
- support requirements,
- forcing status,
- opener's continuations,
- treatment after interference,
- jump raise style.

---

# Vulnerability

Vulnerability affects preemptive jump raises more than constructive raises.

Favorable vulnerability permits

- more aggressive preempts.

Constructive raises remain relatively unchanged.

---

# Expert Style

Modern tournament partnerships almost universally prefer Inverted Minors
because they

- improve constructive bidding,
- reserve jump raises for obstruction,
- simplify game investigation,
- integrate naturally with Two-over-One Game Force.

For many expert pairs, Inverted Minors are considered part of their standard
system rather than an optional convention.

---

# Common Mistakes

## Raising with Only Three Trumps

Most expert methods require **four-card support**.

---

## Ignoring a Four-Card Major

Major-suit fits normally take priority.

---

## Passing the Constructive Raise

The raise is forcing for one round.

---

## Confusing Support Points with HCP

Evaluation should include

- distribution,
- trump length,
- shortness,
- playing strength.

---

## Treating Jump Raises as Invitational

With Inverted Minors,

jump raises are usually preemptive.

# Complete Response Structure

After the constructive raise, opener becomes captain only temporarily and
continues to describe the hand naturally.

Typical continuation:

| Opener's Rebid | Meaning |
|---------------|---------|
| 2NT | Minimum balanced (12–14 or partnership style) |
| 3♣ / 3♦ | Minimum unbalanced hand |
| New suit | Natural second suit |
| Jump in new suit | Extra values |
| 3NT | Balanced maximum |
| Cue bid | Slam interest / control (expert) |

The auction remains forcing for one round.

---

# Opener's Continuations

## Minimum Balanced

```
1♦
2♦
2NT
```

Shows

- minimum opening
- balanced hand
- no singleton
- no extra strength

Responder now decides whether to

- pass,
- invite,
- bid game,
- investigate slam.

---

## Minimum Unbalanced

```
1♣
2♣
3♣
```

- minimum
- long clubs
- unsuitable for notrump

---

- second suit

```
2♣
2♥
```

- extra strength,

others simply as

- shape-showing.

Agreement required.

Possible actions

- sign off,
- invite,
- bid game,
- cue bid,
- RKCB,
- control bidding.

# Slam Investigation

One of the greatest advantages of Inverted Minors is improved slam bidding.

Example

```
1♦
2♦
2♠
3♣
3♦
3♥
```

The partnership exchanges

- controls,
- shortness,
- suit quality,

before committing.

Later auctions may employ

- RKCB,
- Kickback,
- Redwood,
- Cue Bidding.

---

# Cue Bidding

After a constructive raise,

cue bids normally show

- first-round control,
- second-round control,
- slam interest.

Example

```
1♣
2♣
2♦
2♥
```

Heart control.

---

# Shortness Showing

Some expert partnerships use

```
3♥
```

or

```
3♠
```

to show

- singleton,
- void,

after the inverted raise.

These methods improve slam investigation.

---

# Competitive Auctions

When opponents interfere,

partnership agreement determines whether

- Inverted Minors remain on,
- raises become natural,
- doubles replace constructive raises,
- cue bids become limit raises.

---

## Example

```
1♦
(1♠)
2♦
```

Possible meanings

- natural competitive raise,
- constructive raise,
- partnership agreement.

Many experts suspend Inverted Minors after interference.

---

# Passed Hand

Many partnerships **do not** use Inverted Minors as a passed hand.

Example

```
Pass
Pass
1♦
2♦
```

May simply be constructive,

not forcing.

Agreement required.

# Modern Expert Style

Modern tournament partnerships almost universally employ

- Inverted Minors,
- Bergen Raises,
- Jacoby 2NT,
- Mixed Raises,

as complementary constructive methods.

Inverted Minors have become one of the defining conventions of contemporary
minor-suit bidding because they clearly separate

- constructive raises,
- competitive raises,
- preemptive raises,

while preserving maximum bidding space for game and slam exploration.

# Summary

The **Inverted Minors Convention** is one of the most widely adopted
constructive conventions in modern bridge. By reversing the meanings of the
single and jump raises of a minor-suit opening, it enables partnerships to
differentiate between **constructive**, **preemptive**, and **slam-oriented**
hands while preserving valuable bidding space.

Its seamless integration with **Two-over-One Game Force**, **cue bidding**,
**Roman Key Card Blackwood**, and other modern treatments makes it a cornerstone
of expert partnership methods. For serious tournament players, Inverted Minors
is considered a standard component of an efficient and highly descriptive
constructive bidding system.
