# Feature Ask

## Overview

**Feature Ask** is an artificial **2NT inquiry** used after partner opens a **Weak Two**. Unlike **Ogust**, which asks about the **strength of the hand** and the **quality of the trump suit**, Feature Ask requests opener to show an **outside feature**—typically an Ace, King, singleton, or void outside the trump suit.

The convention is particularly useful when responder already knows the partnership has enough strength for game but needs additional information to determine whether slam is possible.

Typical auction:

```
2♥
2NT*
```

or

```
2♠
2NT*
```

The **2NT** response is artificial.

---

# Purpose

Feature Ask is designed to:

- Discover useful outside honors.
- Evaluate slam potential.
- Improve game decisions.
- Exchange information efficiently.
- Avoid poor slam contracts.

---

# When to Use

Feature Ask applies after:

```
2♥
2NT*
```

or

```
2♠
2NT*
```

Responder normally already expects:

- Game to be likely.
- Opener to hold a normal Weak Two.

Unlike Ogust, responder is **not** asking about minimum versus maximum.

---

# Requirements

Responder typically holds:

- Strong hand.
- Game-going values.
- Interest in slam.
- Good support for opener's suit.

Typical strength:

- 15+ HCP
- Or excellent controls and playing strength.

---

# What Is a Feature?

A feature is usually:

- Outside Ace.
- Protected King.
- Singleton.
- Void.

The feature must be **outside opener's trump suit**.

Example:

```
♠ KQJ965
♥ 74
♦ A6
♣ 985
```

Opening **2♠**, the feature is:

```
♦A
```

---

# Standard Responses

The most common agreements are:

## Lowest Available Suit

Shows:

- Club feature.

---

## Next Suit

Shows:

- Diamond feature.

---

## Next Suit

Shows:

- Heart feature.

---

## 3NT

Shows:

- No outside feature.

or

- Excellent trump suit.

depending on partnership agreement.

Every partnership should define these meanings.

# Opener's Rebids

After the inquiry opener simply identifies the feature.

Responder then becomes captain.

Possible continuations include:

- Game.
- Cue bidding.
- Roman Key Card Blackwood.
- Sign off.

---

# Responder's Continuations

After learning opener's feature responder evaluates:

- Controls.
- Combined strength.
- Trump quality.
- Slam prospects.

Possible actions:

- Pass.
- Bid game.
- Cue bid.
- Roman Key Card Blackwood.
- Grand Slam investigation.

---

# Feature Ask vs Ogust

| Feature Ask | Ogust |
|--------------|-------|
| Asks for outside feature | Asks for strength and suit quality |
| Usually game-going hands | Invitational or stronger |
| Slam oriented | Game oriented |
| Does not distinguish minimum/maximum | Distinguishes minimum/maximum |

Many expert partnerships use **Ogust** with invitational hands and **Feature Ask** only when responder already knows the partnership belongs in game.

# Competitive Auctions

## Overview

Feature Ask is primarily intended for uncontested auctions. If opponents interfere, many partnerships abandon Feature Ask in favor of natural bidding or cue bids.

---

## Opponent Overcalls

Example

```
2♠
(3♦)
?
```

Common treatments include:

- Natural bidding.
- Cue bids.
- Feature Ask Off.

---

## Opponent Doubles

Example

```
2♥
(Double)
?
```

Many partnerships play:

- 2NT remains Feature Ask.
- Natural bidding.
- Redouble showing values.

---

## Competition After 2NT

Example

```
2♠
2NT*
(Double)
?
```

Partnership agreements should specify:

- Whether opener still shows the feature.
- Whether Pass is forcing.
- Whether Redouble replaces feature responses.

---

## Slam Investigation

Once opener has identified the feature, responder may continue with:

- Cue Bids.
- Control Bids.
- Roman Key Card Blackwood.
- Exclusion Blackwood (if appropriate).

---

## Partnership Agreements

Partners should define:

- Whether Feature Ask remains on after interference.
- What qualifies as a feature.
- Responses after doubles.
- Cue-bid priorities.
- Blackwood agreements.

---

## General Principles

When using Feature Ask:

- Use it only with genuine game-going hands.
- Ask for controls rather than HCP.
- Continue naturally after the feature is identified.
- Reevaluate after every competitive action.
- Follow partnership agreements consistently.

---

# Advantages

Feature Ask:

- Improves slam bidding.
- Identifies useful outside honors.
- Easy to learn.
- Complements Ogust.
- Preserves bidding space.

---

# Limitations

The convention:

- Requires partnership agreement.
- Gives information to the opponents.
- Has several response structures.
- Is unavailable after some interference.

---

# Variations

Common partnership styles include:

- Ace-or-King Feature Ask.
- Ace-only Feature Ask.
- Singleton Feature Ask.
- Control-showing Feature Ask.
- Combined Ogust/Feature systems.

Every partnership should agree on the exact meanings.

---

# Common Mistakes

## Confusing Feature Ask with Ogust

Feature Ask asks:

- **Where are your controls?**

Ogust asks:

- **How good is your hand and suit?**

---

## Asking Without Slam Interest

Feature Ask is intended for hands that already expect to reach game.

---

## Showing Honors in the Trump Suit

The feature is **outside** the trump suit.

---

## Forgetting Partnership Agreements

Different partnerships define "feature" differently.

---

## Ignoring Competition

Many partnerships suspend Feature Ask after interference.

---

# Tips

- Think of Feature Ask as **"Show me your best outside control."**
- Agree whether Kings qualify.
- Decide whether singletons count as features.
- Practice Feature Ask together with Ogust.
- Remember that controls often matter more than HCP when evaluating slam.

---

# Modern Usage

Modern expert partnerships often use **both Ogust and Feature Ask**, assigning them different purposes:

- **Ogust** for invitational hands needing to know opener's strength and suit quality.
- **Feature Ask** for game-going hands needing to know whether opener holds useful outside controls for slam.

Some partnerships combine both ideas by using different responses to the same **2NT inquiry**, while others choose one convention exclusively.

---

# Summary

Feature Ask is an artificial inquiry used after a Weak Two opening to discover opener's **outside controls** rather than the quality of the weak two itself. By identifying Aces, protected Kings, or other agreed features, the convention allows responder to evaluate slam prospects far more accurately than natural bidding alone. Used alongside Ogust, Cue Bids, and Roman Key Card Blackwood, Feature Ask forms an important part of modern preemptive bidding methods.
