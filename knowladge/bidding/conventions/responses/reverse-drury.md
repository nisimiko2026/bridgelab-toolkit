# Reverse Drury

## Overview

**Reverse Drury** is an advanced variation of the **Drury Convention** used
when responder is a **passed hand** and opener has opened **1♥** or **1♠** in
third or fourth seat.

Like standard Drury, it allows responder to show a constructive raise while
allowing opener to determine whether the opening was full-strength or a light
third-seat opening.

The distinguishing feature is that **the meanings of 2♣ and 2♦ are reversed**
(or redistributed), allowing partnerships to differentiate between various
strength ranges or hand types with greater precision.

Although several versions exist, the most common expert treatment uses one bid
for a simple constructive raise and the other for a stronger constructive or
game-invitational raise.

---

# Objectives

Reverse Drury enables the partnership to

- distinguish multiple constructive raises,
- identify light third-seat openings,
- improve game decisions,
- preserve bidding space,
- evaluate competitive auctions accurately,
- describe passed-hand strength more precisely.

---

# Background

Third-seat openings are frequently lighter than first- or second-seat
openings.

Example

```
Pass
Pass
1♠
```

may contain

- normal opening values,
- or an aggressive light opening intended to disrupt the opponents.

Without Drury, responder cannot determine opener's true strength.

Reverse Drury extends Drury by providing additional descriptive capability.

# Basic Principle

Typical auction

```

Pass
1♠
2♦*
```

Artificial.

Shows

- passed hand,
- four-card or better support,
- constructive values,
- stronger than a simple raise.

The exact meaning depends on partnership agreement.

# Requirements

Typical requirements

- passed hand,
- support for opener's major,
- approximately 9–12 support points,
- constructive values,
- interest in game opposite a maximum opening.

Support is normally

- four cards,
- sometimes three.

- whether doubles replace the convention,
- whether cue bids substitute.

# Vulnerability

Vulnerability affects opener's light openings more than responder's Reverse
Drury response.

At favorable vulnerability,

lighter third-seat openings become more common.

# Expert Style

Most expert partnerships choose one of two methods

- Standard Drury

- system philosophy,

# Expert Partnership Styles

There is **no single standard definition** of Reverse Drury. Common expert
approaches include:

### Two-Way Drury

- **2♣** = minimum constructive raise
- **2♦** = stronger constructive raise

### Shape-Based Reverse Drury

- **2♣** = balanced constructive raise
- **2♦** = distributional constructive raise

### Support-Based Reverse Drury

- **2♣** = three-card support
- **2♦** = four-card support

The partnership should adopt one complete structure and document all continuations.

---

# Modern Expert Recommendations

Reverse Drury is best suited to partnerships that

- frequently employ light third-seat openings,
- play Two-over-One Game Force,
- use aggressive competitive methods,
- want finer distinctions among constructive passed-hand raises.

It complements

- Mixed Raises,
- Bergen Raises,
- Passed-Hand Splinters,
- Passed-Hand Jacoby,

to create a comprehensive passed-hand raising structure.

---

# Summary

**Reverse Drury** is an advanced extension of the Drury convention that allows
passed-hand responder to distinguish different types of constructive raises
after a third- or fourth-seat major-suit opening. By using two artificial
responses instead of one, it provides greater descriptive accuracy and improves
opener's ability to judge whether to compete, invite game, or bid game.

Because several expert versions exist, successful use of Reverse Drury depends
on detailed partnership agreements regarding the meanings of **2♣**, **2♦**,
and all subsequent continuations.
