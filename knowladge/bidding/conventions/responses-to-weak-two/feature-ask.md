# Feature Ask Convention

## Bridge Insight

**Feature Ask allows responder to discover whether opener's Weak Two contains an outside strength that may justify game. Rather than asking "How many points do you have?", responder asks "Where is your useful card?"**

---

# Overview

The **Feature Ask** convention is an artificial inquiry used after partner opens a **Weak Two** (2♦, 2♥, or 2♠). It enables responder to determine whether opener has a useful outside feature that may improve the partnership's chances for game.

Unlike **Ogust**, which evaluates the quality of the Weak Two itself, **Feature Ask** focuses on **outside values**.

The convention is widely played in conjunction with Weak Two openings and often complements Ogust.

---

# Objectives

Feature Ask enables responder to:

- Evaluate game prospects.
- Locate outside honors.
- Judge whether opener's hand contains useful values.
- Improve game bidding decisions.
- Avoid poor games based solely on point count.

---

# When to Use

Typical auction:

```
West      East

2♥        2NT
?
```

or

```
West      East

2♠        2NT
?
```

In partnerships playing Feature Ask, **2NT** asks opener to describe an outside feature rather than suit quality.

Some partnerships instead reserve another artificial bid (such as 3♣) as the Feature Ask, allowing 2NT to be used for Ogust. This is entirely a partnership agreement.

---

# What Is a Feature?

A **feature** is normally:

- An outside Ace.
- An outside King.
- Occasionally a protected Queen (partnership agreement).

The feature **must not be in opener's long suit**.

Example:

```
♠ KQJ985
♥ A6
♦ 83
♣ 742
```

Feature:

```
♥A
```

---

# Typical Responses

The most common treatment:

| Rebid | Meaning |
|--------|---------|
| Cheapest available bid | No outside feature |
| Bid a suit | Ace or King in that suit |
| 3NT | Maximum with excellent playing strength (optional agreement) |

Example:

```
2♠ — 2NT

3♣
```

May show:

```
Club Ace

or

Club King
```

depending on partnership agreement.

---

# Complete Auction Example 1

```
West      East

2♥        2NT
3♠        4♥
```

Meaning:

- Feature in spades.
- Responder judges game is worthwhile.


No useful game opposite the discovered feature.

Responder values the outside Heart Ace and chooses Notrump.

---

# Feature Ask versus Ogust

| Feature Ask | Ogust |
|--------------|-------|
| Shows outside feature | Shows hand strength and suit quality |
| Helps evaluate controls | Helps evaluate offensive potential |
| Focuses on outside honors | Focuses on the Weak Two itself |

Some partnerships play one convention.

Others play both.

---

# Choosing Between Ogust and Feature Ask

Common methods include:

### Method 1

```
2NT = Ogust
```

No Feature Ask.

---

### Method 2

```
2NT = Feature Ask
```

No Ogust.

---

### Method 3

```
2NT = Ogust

3♣ = Feature Ask
```

This is increasingly popular because it preserves both conventions.

---

# Advantages

Feature Ask:

- Locates useful honors.
- Improves game judgment.
- Helps responder visualize the combined hands.
- Requires little memory.

---

# Limitations

Feature Ask:

- Does not describe suit quality.
- Does not distinguish minimum from maximum.
- Consumes bidding space.
- Depends on partnership agreement.

---

# System Variations

Partnerships differ regarding:

- What qualifies as a feature.
- Whether Kings qualify.
- Whether Queens qualify.
- Which bid initiates the inquiry.
- Priority relative to Ogust.

These agreements should be recorded on the convention card.

---

# Expert Thinking

Experts understand that **outside controls often determine whether game succeeds**.

A Weak Two with:

```
♠ KQJ1097

♥ A4
```

is frequently worth far more than:

```
♠ KQJ1097

♥ J4
```

The Feature Ask identifies those hidden assets.

---

# Common Mistakes

- Counting honors in opener's long suit as a feature.
- Asking without genuine game interest.
- Forgetting the partnership agreement.
- Ignoring suit quality.
- Confusing Feature Ask with Ogust.

---

# Best Practices

- Agree precisely what constitutes a feature.
- Decide whether Kings count.
- Use Feature Ask only when the answer may affect the final contract.
- Combine the answer with your own hand evaluation.

# Expert Tip

**Feature Ask and Ogust answer different questions.**

Ogust asks:

> "How good is your Weak Two?"

Feature Ask asks:

> "Where is your useful outside honor?"

Strong partnerships often incorporate both methods into their Weak Two structure.

---

# Memory Aid

**Feature Ask = "Where Is Your Extra Honor?"**

Remember:

- The inquiry seeks outside strength, not suit quality.
- Features are normally outside Aces or Kings.
- The convention helps responder evaluate whether game is realistic.
- It complements rather than replaces Ogust.
- A single outside control can transform a marginal game into an excellent contract.
