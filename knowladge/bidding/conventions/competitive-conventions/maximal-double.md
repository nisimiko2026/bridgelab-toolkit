# Maximal Double Convention

## Purpose

The **Maximal Double** is used in competitive auctions after your partnership has found a major-suit fit and the opponents have taken away bidding space. The double distinguishes between **invitational** and **non-invitational** game tries.

Without the convention, it is often difficult to tell whether a bid is merely competitive or a genuine game invitation.

The Maximal Double allows the partnership to:

- Make clear game tries.
- Compete accurately when bidding space is limited.
- Differentiate between competitive raises and invitations.
- Improve game decisions.

---

# When It Applies

The convention applies when:

- Your partnership has agreed on a major suit.
- The opponents compete immediately below game.
- There is **no room for a natural game try**.

Typical auctions:

```
1♠   Pass
2♠   3♥
?
```

or

```
1♥   Pass
2♥   3♦
?
```

The opponents have taken away the available game-try bid.

---

# Basic Principle

| Opener's Action | Meaning |
|-----------------|---------|
| **Double** | Invitational game try (Maximal Double) |
| **3M** | Competitive only |
| **4M** | To play |

The Double is **artificial** and **not for penalties**.

# Requirements

Typical hand:

- Extra values beyond a minimum opening.
- Interest in game.
- No clear natural game-try bid available.

Usually:

- About **15–17 total points** (high-card points plus distribution), depending on partnership style.

---

# Partner's Evaluation

After a Maximal Double, responder should evaluate:

- Trump support.
- Useful controls.
- Shortness.
- Overall playing strength.

### Minimum Hand

Return to the agreed major.

Example:

```
1♠
Pass
2♠
3♥
Double
Pass
3♠
```

Invitation declined.

---

### Maximum Hand

Bid game.

Example:

```
1♥
Pass
2♥
3♦
Double
Pass
4♥
```

Invitation accepted.

# What a Maximal Double Does NOT Show

A Maximal Double is **not**:

- A penalty double.
- A takeout double.
- A support double.
- A slam try.

It simply asks:

> "Partner, do you have enough to bid game?"

# Partnership Agreements

Agree on:

- Which auctions qualify for Maximal Doubles.
- Whether the convention applies only after simple raises.
- Minimum strength required.
- Whether it applies after fit-showing jumps.
- Whether doubles become penalty doubles at higher levels.

---

# Advantages

- Clearly distinguishes game tries from competitive bids.
- Prevents misunderstandings.
- Uses bidding space efficiently.
- Widely played by experienced partnerships.
- Excellent companion to modern competitive methods.

---

# Disadvantages

- Gives up the natural penalty double.
- Requires partnership agreement.
- Applies only in specific competitive auctions.

---

# Common Partnership Style

Most expert partnerships play:

- Double = **Game try**.
- 3 of the agreed major = **Competitive**.
- 4 of the agreed major = **To play**.
- Applies when the opponents bid immediately below the game level of the agreed major.

Examples:

```
1♠ – Pass – 2♠ – 3♥
```

and

```
1♥ – Pass – 2♥ – 3♠
```

# Memory Aid

**Maximal Double = "Maximum interest in game."**

Remember:

- **Double = Game Try**
- **3 of the agreed major = Competing only**
- **4 of the agreed major = To play**

The Maximal Double is a valuable competitive convention that preserves a clear distinction between **competitive bidding** and **game invitations** after the opponents have consumed valuable bidding space.
