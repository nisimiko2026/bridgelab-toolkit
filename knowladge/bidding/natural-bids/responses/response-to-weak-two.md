# Response to Weak Two Opening

## Overview

Responding to a **Weak Two opening** requires balancing constructive bidding
with the recognition that opener has already described a **limited hand**.

Unlike constructive one-level openings, a Weak Two is primarily

- preemptive,
- obstructive,
- descriptive.

Responder's task is to determine whether the partnership should

- pass,
- compete,
- bid game,
- sacrifice,
- or, in rare cases, investigate slam.

Because opener's strength is already limited, responder generally becomes
captain of the auction.

---

# Meaning of a Weak Two

A Weak Two opening normally promises

- 5–10 HCP,
- a good six-card suit,
- offensive distribution,
- no hand suitable for a one-level opening.

The bid is

- natural,
- preemptive,
- limited.

---

# Objectives

Responder should

- evaluate game prospects,
- judge the offensive potential,
- determine whether to compete,
- investigate game only when justified,
- avoid unnecessary bidding.

---

# Evaluating the Hand

Responder should consider

- High Card Points,
- trump support,
- controls,
- side-suit strength,
- distribution,
- vulnerability,
- offensive potential.

Distribution is frequently more important than HCP.

---

# Typical Strength Categories

| Strength | Typical Action |
|----------|----------------|
| 0–10 HCP | Usually Pass |
| 11–14 HCP | Constructive action |
| 15+ HCP | Investigate game |
| Exceptional | Rare slam exploration |

---

# Passing

The most common action.

Example

```
2♠
Pass
```

Responder passes with

- weak hand,
- no fit,
- little game potential.

---

# Simple Raise

Example

```
2♥
3♥
```

Shows

- good support,
- constructive values,
- interest in competing.

Usually not invitational.

---

# Raise to Game

Example

```
2♠
4♠
```

Shows

- strong trump support,
- expectation that game will make,
- offensive values.

Responder normally bases this decision on

- distribution,
- fit,
- playing strength,

rather than HCP alone.

---

# New Suit Response

Example

```
2♥
3♣
```

Usually

- natural,
- forcing,
- strong.

Shows

- genuine suit,
- game interest,
- desire for additional information.

---

# 2NT Feature Ask

The most common expert treatment.

Auction

```
2♠
2NT
```

Artificial.

Requests opener to describe

- outside ace,
- outside king,
- useful feature,
- maximum,
- minimum.

Responder intends to decide whether game is possible.

---

# Ogust Convention

Many partnerships replace Feature Ask replies with **Ogust**.

After

```
2♥
2NT
```

opener describes

- minimum or maximum,
- poor or good suit.

Typical structure

| Response | Meaning |
|----------|---------|
| 3♣ | Minimum, poor suit |
| 3♦ | Minimum, good suit |
| 3♥ | Maximum, poor suit |
| 3♠ | Maximum, good suit |

# Major-Suit Openings

After

```
2♥
```

or

```
2♠
```

major-suit games become the primary objective.

Responder should aggressively evaluate

- trump fit,
- shortness,
- offensive values.

---

# Notrump Contracts

Responder may choose

```
3NT
```

when holding

- stoppers,
- strong outside values,
- confidence that opener's long suit will provide sufficient tricks.

---

# Slam Investigation

Rare.

Only unusually powerful responder hands justify exploring slam.

When slam is considered,

cue bidding and Roman Key Card Blackwood may be used after a fit is established.

---

# Competitive Auctions

If opponents interfere,

responder should evaluate

- fit,
- vulnerability,
- sacrifice possibilities,
- defensive strength.

Common actions include

- raise,
- double,
- cue bid,
- natural new suit.

---

# Partnership Agreements

Partners should define

- Feature Ask,
- Ogust,
- forcing new suits,
- raises,
- game tries,
- competitive methods,
- fourth-seat style,
- vulnerability adjustments.

---

# Modern Expert Methods

Most expert partnerships employ

- Feature Ask
- Ogust
- disciplined game raises
- natural forcing new suits
- aggressive game bidding with good fits

These methods maximize constructive accuracy while preserving the preemptive
value of the opening.

# Summary

Responding to a **Weak Two opening** requires responder to become the captain of
the auction. Since opener has already described a **limited hand with a long
suit**, responder's primary responsibility is to evaluate whether the combined
assets justify passing, competing, bidding game, or, on rare occasions,
investigating slam.

Modern methods centered on **Feature Ask** and **Ogust** enable partnerships to
distinguish between minimum and maximum Weak Twos while preserving the
preemptive nature of the opening. Successful responses depend on careful
evaluation of **fit**, **distribution**, **playing strength**, and
**vulnerability**, rather than relying solely on High Card Points.
