# Opener After a 1NT Opening

## Overview

After opening **1NT**, opener has already described

- strength,
- distribution,
- balanced shape,
- limited hand.

Unlike one-level suit openings, opener's subsequent bids are not used to further
describe the hand. Instead, opener's responsibility is to

- answer responder's conventional inquiries,
- complete transfer sequences,
- cooperate in game and slam investigation,
- remain faithful to the agreed strength range.

Because responder knows far more about the partnership's combined assets,
**responder normally becomes captain of the auction.**

---

# Objectives

After opening 1NT, opener should

- answer conventional bids accurately,
- preserve bidding space,
- avoid unnecessary description,
- cooperate in slam exploration,
- remain within the agreed system.

---

# General Principles

Since opener has already limited the hand,

subsequent bidding is based primarily upon

- responder's strength,
- responder's distribution,
- responder's intentions.

Opener should avoid introducing new information unless requested.

---

# Accepting Transfers

One of opener's most common responsibilities.

Example

```
1NT
2♦
2♥
```

Opener completes the transfer.

Likewise

```
1NT
2♥
2♠
```

Transfer acceptance is normally automatic.

---

# Super Accepts

Some partnerships employ **Super Accepts**.

Example

```
1NT
2♦
3♥
```

May show

- maximum,
- four-card support,
- excellent trump quality.

Partnership agreement required.

---

# Responding to Stayman

Auction

```
1NT
2♣
```

Opener replies

```
2♦
```

No four-card major.

---

```
2♥
```

Four hearts.

---

```
2♠
```

Four spades.

If holding both majors,

most partnerships respond

```
2♥
```

unless using special methods.

---

# Responding to Puppet Stayman

After

```
1NT
3♣
```

(opener's agreement)

reply according to the agreed Puppet Stayman structure.

Purpose

- identify five-card majors,
- locate 4-4 fits,
- improve slam bidding.

---

# Responding to Texas Transfers

Example

```
1NT
4♦
4♥
```

Transfer completion is automatic.

The same principle applies to

```
1NT
4♥
4♠
```

---

# Responding to Minor Transfers

Where played,

opener accepts the transfer unless partnership agreement specifies otherwise.

---

# Quantitative 4NT

Auction

```
1NT
4NT
```

Responder invites slam.

Opener

- passes with a minimum,
- bids 6NT with a maximum.

No ace-counting occurs.

---

# Gerber

Example

```
1NT
4♣
```

If Gerber is played,

opener replies

| Response | Aces |
|----------|------|
| 4♦ | 0 or 4 |
| 4♥ | 1 |
| 4♠ | 2 |
| 4NT | 3 |

Partnership agreements may vary.

---

# Responding to Smolen

After responder employs Smolen,

opener simply

- supports responder's major,
- cooperates naturally,
- continues slam investigation when appropriate.

---

# Responding to Invitational Auctions

Examples

```
1NT
2NT
```

Opener

- passes with minimum,
- bids 3NT with maximum.

---

# Responding to Sign-Off Auctions

Example

```
1NT
2♦
2♥
Pass
```

The auction ends.

Opener should not continue.

---

# Responding to Slam Investigation

When responder begins slam exploration,

opener should accurately show

- controls,
- key cards,
- kings,
- cue bids,
- partnership agreements.

Common methods include

- Roman Key Card Blackwood,
- cue bidding,
- control bidding,
- Gerber.

---

# Competitive Auctions

After interference,

opener follows partnership agreements.

Common methods include

- Lebensohl,
- Rubensohl,
- Transfer Lebensohl,
- System On,
- System Off.

---

# Balanced Philosophy

Opener should remember

the hand has already been described.

Avoid

- unnecessary rebids,
- speculative bidding,
- introducing suits naturally.

Responder is directing the auction.

---

# Declarer Considerations

Transfers are valuable because

they allow the strong hand

(opener)

to become declarer.

This

- protects honors,
- conceals information,
- improves play.

---

# Partnership Agreements

Partners should define

- exact 1NT range,
- Stayman structure,
- Jacoby Transfers,
- Super Accepts,
- Texas Transfers,
- Puppet Stayman,
- Minor Transfers,
- Gerber,
- Quantitative 4NT,
- competitive methods.

# Summary

After opening **1NT**, opener's role changes from **describing the hand** to
**cooperating with responder's plan**. Since the opening bid has already
defined both strength and distribution, responder becomes captain and directs
the auction toward the best partscore, game, or slam.

Successful 1NT continuations rely on disciplined responses to **Stayman**,
**Jacoby Transfers**, **Texas Transfers**, **Puppet Stayman**, **Gerber**, and
**Quantitative 4NT**, together with consistent partnership agreements. Opener's
greatest contribution is accuracy and restraint—providing exactly the
information responder needs and nothing more.
