# Game Trial Bids

## Definition

A **game trial bid** (also called a **game try**) is a bid made after a partnership has agreed on a suit fit, inviting partner to continue to **game** if they hold suitable additional values.

Unlike a slam try, a game trial bid asks:

> **"Do we have enough for game?"**

rather than:

> **"Can we make a slam?"**

Game trial bids are among the most important invitational tools in bridge because they help partnerships accurately judge whether to stop in a partscore or bid game.

---

# Objectives

A game trial bid aims to:

- Investigate the possibility of game.
- Allow partner to evaluate their hand more accurately.
- Describe where additional help is needed.
- Reach good games.
- Avoid poor games.
- Improve partnership hand evaluation.

---

# General Principle

A game trial assumes:

- A trump fit has already been established.
- Game is **possible**, but **not certain**.
- The bidder has extra interest in game.
- Partner's fitting values will determine the final decision.

Example:

```
South      North

1♠
2♠
3♣
```

South has invited game.

---

# When Game Tries Occur

Most commonly after:

```
1♥
2♥

or

1♠
2♠
```

where responder has made a simple raise.

The opener has extra values but not enough to bid game unilaterally.

---

# Requirements

Typical opener:

- Approximately 15–17 HCP
- Extra playing strength
- Good distribution
- Good trump suit
- Interest in game

Responder decides whether to accept.

---

# Types of Game Trial Bids

Several methods are used.

---

# Help Suit Game Try (HSGT)

The most common expert method.

The opener bids a new suit asking:

> "Can you help me in this suit?"

Help may include:

- High honors
- Shortness
- Length
- Useful intermediates

Example:

```
1♠
2♠
3♦
```

Meaning:

"I have game interest. Diamond values will help."

---

# Long Suit Game Try

Shows:

- Extra length
- Potential source of tricks
- Need for help in that suit

Example:

```
1♥
2♥
3♣
```

Usually six or more clubs.

---

# Short Suit Game Try

Shows:

- Singleton or void
- Extra distribution
- Desire for partner's fitting cards

Example:

```
1♠
2♠
3♣
```

Depending on partnership agreement, this may show club shortness rather than club length.

---

# General Game Try

Some partnerships use any new suit simply as:

> "I have extras. Please evaluate."

No distinction is made between long and short suits.

---

# Two-Way Game Tries

Advanced partnerships distinguish:

- Long suit tries
- Short suit tries

using different bidding structures.

---

# Artificial Game Tries

Some systems employ artificial bids instead of natural suit bids.

Examples include:

- 2NT Game Try
- Relay game tries
- Modified Bergen methods
- Scandinavian methods

These require explicit partnership agreement.

---

# How Responder Evaluates

Responder should not rely solely on high-card points.

Instead, evaluate:

- Controls
- Trump support
- Fitting honors
- Shortness
- Useful intermediates
- Working cards
- Distribution

---

# Helpful Cards

Partner welcomes:

```
Kxx
AQx
QJx
```

in the trial suit.

Example:

```
Opener:
♣AQJ876

Responder:
♣K42
```

Excellent fit.

---

# Poor Fitting Cards

Example:

```
Opener:
♣AQJ876

Responder:
♦KQJ
```

Diamond honors contribute little.

---

```
1♥
2♥
3♣
```

Responder now chooses between:

```
3♥
```

Decline invitation.

or

```
4♥
```

Accept invitation.

# Example 1

```
South      North

1♠
2♠
3♦
4♠
```

North has useful diamond values.

Game accepted.

---

# Example 2

```
South      North

1♥
2♥
3♣
3♥
```

North lacks club help.

Invitation declined.

---

# Example 3

```
South      North

1♠
2♠
3♦
Pass
```

Not permitted.

A game try is invitational.

Responder must choose between:

```
3♠
```

or

```
4♠
```

---

# Evaluation Guidelines

Responder should upgrade with:

- Useful honors
- Double fit
- Singleton
- Void
- Excellent trumps
- Controls
- Extra shape

Downgrade with:

- Soft queens
- Poor intermediates
- Flat hand
- Wasted honors
- Values opposite opener's shortness

---

# Distribution

Distribution often determines success.

Example:

```
♠KQxx
♥xxx
♦x
♣QJxxx
```

may be superior to

```
♠KQxx
♥Qxx
♦Qxx
♣Qxx
```

despite identical HCP.

---

# Partnership Agreements

Partners should agree:

- Help suit or long suit?
- Short suit game tries?
- Artificial methods?
- Two-way game tries?
- Minimum opener requirements?
- Acceptance standards?

---

# Common Methods

Popular approaches include:

- Help Suit Game Try (most common)
- Long Suit Game Try
- Short Suit Game Try
- Two-Way Game Tries
- Artificial 2NT Game Try
- Relay Game Tries

---

# Common Mistakes

## Counting Only High-Card Points

Distribution usually matters more.

---

## Ignoring Suit Fit

Useful honors in opener's trial suit are extremely valuable.

---

## Automatic Acceptance

Responder should evaluate thoughtfully rather than simply counting points.

---

## Misunderstanding the Trial Suit

Partnerships must know whether the bid shows:

- length,
- weakness,
- shortness,
- or merely game interest.

---

## Forgetting System Agreements

Different systems interpret game tries differently.

Always follow partnership agreement.

---

# Expert Principles

Experienced partnerships:

- Evaluate fitting values.
- Upgrade controls.
- Downgrade wasted honors.
- Prefer shape over flat hands.
- Judge trick-taking potential rather than HCP alone.

Modern bridge places far greater emphasis on **playing strength** than on simple point count.

# Comparison with Slam Trial Bids

| Feature | Game Trial Bid | Slam Trial Bid |
|----------|----------------|----------------|
| Purpose | Investigate game | Investigate slam |
| Contract already assured | No | Yes |
| Typical level | 2–3 | 4–5 |
| Trump fit established | Yes | Yes |
| Usually invitational | Yes | No |
| Focus | Playing strength for game | Controls, keycards, and slam potential |

---

# Memory Aid

A useful guideline is:

> **A game trial bid asks: "Can we make game?"**

while

> **A slam trial bid asks: "Can we make slam?"**

---

# Key Points

- A game trial bid invites partner to bid game if suitable values are held.
- It is made after a trump fit has been established but before game is certain.
- Help Suit Game Tries are the most widely used method.
- Distribution, controls, and fitting honors are more important than raw HCP.
- Successful partnerships evaluate hands based on trick-taking potential rather than point count alone.
- The exact meaning of a game trial bid depends on the partnership's agreed methods.
